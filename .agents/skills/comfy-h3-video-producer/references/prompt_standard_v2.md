## 二、H3 房规骨架（七段，缺一不可）

```
subject_definitions:
- 色彩/关键帧参考（如有）
- <Subject 1> 为 @图片1 中的…，尺度锚点=…；权限=…
- <Subject 2> 为 @图片2 中的…（场景）…；权限=锁定空间，不复制原图机位，不复制它的占画比例。
- 文字定义：参考图里没有的元素（自造道具/地点），一句话说清尺度与材质。
- <Audio 1> 为 <Subject 1> 的声线锚定：……（见第四节）

summary:
[参考生成 + 音频参考] 目标视频呈现……（一句话核心事件）；以 <Subject 2> 承载……；<Audio 1> 用作 X (S1) 的对白音色；无背景音乐、无持续环境音，只保留对白与画面动作直接产生的短拟音。

detailed_description:
（风格行：画风 + 色调对撞关系，一句压完）
情感弧线：一句话定本段的节奏骨架与景别走向（静→稳→重锤→留白），每个节拍的动作都顺着它落（见三-⑥）
时间光线：时刻/光源/照度范围 + 光照-表面交互（见三-④）
时间位置：本段在全片时间轴的位置（可选）
空间环境：<Subject 2>；……
方位参照：东/西/南/北 = 什么；中心参照物；基准机位与主轴线
规模锚点：几人几物，各是什么
环境次级运动：3-4 项持续微动（见三-③）
[节拍 1] 镜头：… 画面：… 神态：… 环境：… 音效：…
[节拍 2] …（台词块排在本拍**最前面**，动作串挪到 <d> 之后；见 4.3.1）
[结尾状态] …（写成"完成态"，并加一句"不允许停在…"）
overall_soundscape:
（见第四节）
non_diegetic_music:
禁BGM/字幕/水印/UI/Logo
防错约束：
- …（只写本段真会犯的错，3-6 条）
```

节拍数量按帧数定：**124帧(5s) → 2-3拍；175帧(7.3s) → 3-4拍；243帧(10s) → 3-4拍**。每拍 2-3 秒，一拍只承担一个主事件。

**一拍最多两个动作。** 四件事塞进 7 秒，模型会砍掉最不起眼的那个（实测：搬电瓶、擦手看车、上车发动、驶离四件事 → "坐进驾驶位"和"拧钥匙着车"整段消失，画面从站在车门边直接跳到车在路上）。要么拆拍，要么把独立小动作并进相邻拍。

**`[结尾状态]` 要写成"死条款"，不是"愿望"**：

模型在最后一拍会挑"最有意思的动作"来填满预算。如果结尾该做 A，而同拍里还写了更有意思的 B，
B 会抢走全部时间、A 直接不做（实测：结尾该关门，但同句写了"双手放在方向盘下缘" →
7 秒预算全给了后者，门大开没关）。三招**一起用**才有效：

1. **删掉一切与结尾主动作竞争的描述**（删"双手放在方向盘下缘"，只留"右手仍扣在门内拉手上不放"）
2. **把小动作前移一拍**，结尾那拍只留两个动作
3. **写成状态型句子**：`[结尾状态] 门扇与门框合上没有缝、看不到车室内部；不允许停在门半开、门大开。`

状态型比过程描述管用得多：过程描述它做一半就停，状态型它得做到位才算完。

**一拍 = 一个镜头位。** H3 支持段内多镜头：换景别/机位/角度就在该拍 `镜头：` 开头明写「**硬切至**……」，同镜延续写「**接上一镜**，机位不变」。不写这两个词，H3 会默认用运镜连过去，切点变软。

**【建议项 v2.2】运镜三要素写在镜头句内，不堆拍末。** 官方失败诊断第一条就是
"运镜被忽略 ← 写成结尾的 tag 堆栈"。完整运镜表达 = **类型 + 幅度 + 速度**，
作为自然句子写进 `镜头：` 描述内部（词汇表见 `references/official/base-en.txt` §4.3）：

- 写：「镜头：硬切至近景，机位随她右移小幅度、慢速，始终装得下……」
- 不写：「……。镜头：右移、慢、小幅度」（tag 堆在拍末，等于没写）
- 幅度/速度省略规则：中等幅度、常速可以不写；**一旦要控制幅度或速度，就必须写出量词**
- 与既有硬边界的关系不变：位移式运镜（推/拉/移）服从度低（SKILL.md §4.1），能不写就不写；此条管的是"写的时候怎么写"，不是"该不该用"

**`权限=` 必须包含「不复制原图机位，不复制占画比例」。** 参考图会压过文字里的景别描述：
实测 Subject 权限只写"锁定车型轮廓与识别特征"，H3 拿到一张主体占满画面的 3/4 参考照，
就按参考图的占画比例画成近景——文字里写的"大远景""车只占画面 1/6"全部失效。

```
权限=锁定车身轮廓与四个识别特征（…）；不复制参考图的机位，不复制它的占画比例，
车在画面里的大小由镜头描述决定。
```

**【建议项 v2.2】排除面写全，不只排除机位。** `权限=` 的本质是给参考素材划边界：
凡参考素材自带、但本段**不要**它管的属性，都要点名排除（官方 Ref2VA 指南口径：
每个参考"定义它控制什么，也定义它不控制什么"）。两种参考最常漏的排除面：

- **动作/视频参考**：写「<Video 1> 只定义手部轨迹与运动时机；不复制它的演员、服装、场景、灯光与运镜」
- **多图来源**：两图都含强光线信息时，显式指定谁赢——「光线以 @图片1 为准，忽略 @图片2 的光斑方向」

**【建议项 v2.2】retention 保留分析（Ref2VA 段适用）。** 对段内每个 `<Subject N>`，
在 `权限=` 之后补一个保留级别（官方四级，Ref2VA 段建议至少给身份类 Subject 标注）：

| 级别 | 含义 | 什么时候用 |
|---|---|---|
| `fully_preserved` | 定义的角色完全保留 | 主角身份/服装（默认） |
| `partially_preserved` | 部分特征改变 | 剧情要求换装/受伤时 |
| `attribute_transfer` | 特征转移到另一主体 | 换人穿同款 |
| `weak_reference` | 只借风格/氛围/构图 | 色调参考、构图参考 |

写法示例：`<Subject 1>（保留级别：fully_preserved）为 @图片1 中的…；权限=…`

**官方诊断逻辑（值得记）**：生成结果里参考特征被改动了 → 优先修 `subject_definitions`
里的权限/保留定义，**不是修镜头描述**。镜头描述只管"这一拍发生什么"，"它长什么样"永远归权限管。

**镜头与景别只能正向描述。** H3 对「景别不变 / 不推近 / 不推拉」服从度低（写了照样推近），
但对「画面里必须装得下什么」服从度高。所以把否定句改成正面描述：
写「画面始终装得下整扇车门的高度（门框上沿到踏板）」，不要写「不要推近」。
位移式运镜（推/拉/移）另有硬边界，见 SKILL.md §4.1。

段内的切镜只受两条限制：**不切空间（地图）**、**不切主要事件**。跨空间或跨时空（现在↔三年前）必须拆段。单镜时长别低于 1.5 秒（来不及时建立画面，会闪）。

### FL2VA 首尾帧段：@图片N 的另一种角色 + 「可观察路径」写法

`@图片N` 有两种用法，`subject_definitions` 里必须声明本段用的是哪种：

| 用法 | 图片角色 | Subject 行写法 |
|---|---|---|
| **Ref2VA 锚定**（默认） | 身份/场景的**可复用参考** | `<Subject 1> 为 @图片1 中的…；权限=…` |
| **FL2VA 首尾帧锚**（精简版工作流常用） | 图片1=**本段起点帧锚**、图片2=**本段终点帧锚**（构图/状态锚点） | `<Subject 1> 为 @图片1 中的…，@图片1 同时是本段起点帧锚；权限=锁定外观，不复制原图机位，不复制占画比例` |

首尾帧段**常配合续接**：图片1 直接用上一段段尾帧，图片2 用本段目标构图。此时段首状态已被钉帧锁死，正文不用再描述"怎么开始"，只描述**从它出发**。
（v3.8 口径对齐：这种"从上段尾帧出发连续演化"的 FL2VA 段属于**真·长镜头例外**——叙事确实要延续才用，尽量少用。常规续接段不是这样：[节拍 1] 直接写新镜头，钉帧状态由裁头机制收回，见 SKILL.md §4。）

**官方推荐的核心写法：描述两个端点之间的可观察路径，不要分别描述两张图。** 即写：
- 姿态/位置怎么从起点状态连续变化到终点状态（谁、哪个部位、朝哪个方向、经过什么）
- 物体被谁、用什么动作操作到末帧状态
- 构图与光线如何逐渐汇聚到图片2（"人物最终停在与图片2一致的位置：背对机位、居中、与钟面同框"）

反面写法（常见错）：正文前半段描述图片1、后半段描述图片2，中间没有"怎么过去"的路径——
H3 只好自己编路径，常见后果是瞬移、跳切或末帧对不上。**端点已经钉死了，路径才是提示词唯一要生产的东西。**

路径写完照常过四层动力学与光照-表面交互（三-②④）——它们描述的就是"路径中段"的画面。

## 三、Seedance 2.5 五条硬规则 → 填哪个槽

### ① 情绪 → 物理分解 → 填 `神态：`

**禁止**：茫然、疑惑、平静、悲伤、紧张、犹豫、欣慰、失落、期待……情绪词零容忍。
**改写**：2-3 个可见肌肉动作 + 紧跟下一个动作。

| 别写 | 写成 |
|---|---|
| 眼神茫然 | 视线停在珠面上不动，眼睑每 3 秒闭合一次，闭合约 0.2 秒后张开，眉毛位置不变，眉心无纵褶 |
| 犹豫 | 视线在珠子与手背之间移动两次，嘴唇张开 2mm 未出声又闭合，右脚跟离地 1cm 又落回 |
| 平静 | 眉心平展，嘴角两端保持水平，下颌不上抬；肩背保持不动，每 3-4 秒眨眼一次 |
| 失落 | 眼睑下垂遮住眼球的上一半，嘴角两端下压 1mm，喉结上下走了一次，肩线向下沉 5mm |

**写完检查：把正文里所有情绪词划掉换成动作，一个不剩。**（"极轻地问"这类也是情绪词，改成"送气量降到最低，声带闭合不完全"→ 但这类不必写进画面，写进台词的表演括号里）

> **⚠️ 呼吸不能写进文本（实测，代价是整段重抽）**
> H3 会把「胸腔每 2.5 秒起伏一次」当成**发声指令**，真的生成一段呼吸声。
> 后果不只是多一个声音：那两段呼吸（实测 1.39s / 0.75s，−16 / −15.5 dBFS）被算成"长事件"，
> 把 `speech_end` 顶到段末，段尾留白判 0，整段必须重抽。
> 改成「肩背保持不动，只有每三到四秒一次眨眼与发梢摆动」后**立刻 PASS**。
>
> **规则**：不自主反应只写**看得见且不出声的位移** —— 眨眼、发梢与衣角摆动、身体微晃、指尖自然弯曲。
> 凡是呼吸 / 心跳 / 喘气 / 叹气 / 吞咽**动作**，一律不写；确实需要"吞咽"这个信息，写成
> 「喉结上下走了一次」（描述位移，不是动作）。

### ② 全身动力学链 → 填 `画面：`

任何动作都必须写全四层，**只写一个部位 = 恐怖片式僵直**：

1. **主动件** — 做核心动作的部位（颈椎右旋 30°）
2. **稳定件** — 维持平衡（双脚不动，重心移到左脚）
3. **补偿件** — 自然联动（右肩跟转 5°，前臂外旋）
4. **不自主反应** — 呼吸/眨眼/微晃/发梢衣角随动

「站着不动」也要写：`重心压在右脚，左脚外撇 15°，双手垂在身侧指尖自然弯曲，肩线保持不动，每 3-4 秒眨眼一次，身体有 2-3mm 自然微晃，衣角随微风摆动。`
（注意：**不要写"胸腔起伏"这类呼吸描述**，见上面 ① 的警告框。）

### ③ 环境动态 → 填 `环境次级运动：`（全局）+ 每拍 `环境：`

**不写 = 死画面 = 假。** 每段 3-4 项，每拍至少 1 项，必须带**方向 + 频率/幅度**。

- 空气类：风（从画面左侧持续吹入，衣角每秒摆动 2 次，幅度 1-2cm）、悬浮尘粒在星光里缓慢左飘
- 光类：珠面暖光随呼吸微幅涨落、灯焰尖端每秒抖动 3-4 次、光斑在地面跳动
- 物体类：沙面表层细沙贴地流动、发梢随同一风向摆动、碎岩边缘积沙被风带走
- 温度类：冷夜呼出的白气在唇前 10cm 处散开（有对白时慎用，会干扰口型）

### ④ 光照-表面交互 → 填 `时间光线：`

角色不是独立打光的。每个可见角色写全五条：

1. 主光源来自哪里、什么色温
2. 照到角色哪个部位（发顶/肩线/半张脸）
3. 第二个光源（道具/火焰/珠光）从哪个方向打哪（掌心/下颌/锁骨内侧）
4. 反射光（沙面/石壁向上垫在下颌阴影里）
5. 阴影落点（眉骨在眼窝投出阴影，鼻侧投影落到左脸）

例：`星光为唯一环境主光，冷蓝自上方铺下，落在发顶、肩线与鼻梁上缘；掌心琥珀珠为唯一暖光源，暖橘自下方打在掌心、下颌与锁骨内侧，形成与顶光对撞的第二个色温区；沙面向上反射极弱冷光垫在下颌阴影内；眼窝在眉骨下留阴影，鼻侧投影落到左脸。`

### ⑤ 四层画面枚举 → 填 `画面：`

| 层 | 必写内容 |
|---|---|
| 前景（0-2m） | 有什么、材质（湿/干/裂/半埋）、光怎么打、动不动 |
| 中景（角色层） | 全身动力学链 + 神态物理分解 + 光照落点 + 脚/手与地面的接触面反应 |
| 背景（8m+） | 有什么、有没有在动、大气透视（远山偏冷/沙尘模糊边缘） |
| 空气层 | 尘粒/雾/温度效果 + 光在空气中的传播（有光源+粒子就写丁达尔） |

**画面"很空"的时候，99% 是漏了空气层。**

### ⑥ 情感弧线 → 填 `detailed_description` 段首 `情感弧线：` 一行（段级，只一句）

整段先给一条**节奏骨架 + 景别走向**，每个节拍的动作都顺着它落，模型拿到的是"先静→再稳→重锤→留白"的完整结构，不是零散动作。

**完整句式（节奏词 + 景别走向 + 闭合弧线，三部分缺一不可）**：

```
情感弧线：节奏自[起点状态]起步、[中段节拍]走[能量走向]、[重锤位置]落下重拍；
          景别由[起幅景别]收进[中段景别]再拉回[收幅景别]，形成一次闭合的情绪弧线。
```

- **节奏词**只描述**能量曲线**（静 / 稳 / 紧 / 重锤 / 留白 / 余韵），不写情绪词（情绪词仍按三-① 物理分解，这里只给曲线）。
- **景别走向**用中英双标 + 运镜量值（可选增强，见下）：写"中景（Medium）、缓慢微推"比单写"中景"更稳，术语帮模型定位机位、物理描述兜底执行。
- **闭合弧线**指景别首尾呼应（收进→拉回 / 拉远→收进），让一段形成完整情绪回路，不是开放式。
- 与第 0 步导演调度的【节奏说明】同源：弧线就是那场戏张力曲线的压缩版，**最高点（重锤）只有一个**。
- 焦段切换（可选增强）：重锤那拍可加「Rack Focus 焦点由[物件]移到[面部]」，让画面重心随动作走。

**三类典型弧线范例（按段功能选）**：

| 段功能 | 弧线范例 | 适用 |
|---|---|---|
| 铺垫段（建空间 + 定关系） | `节奏自静置起步、末镜落脚特写收稳；景别由大远景建立空间→中景定关系→近景收紧→特写最小动作，形成一条下沉的静默铺垫曲线。` | 全片开场、空镜建立 |
| 升级段（媒介/动作推进） | `节奏自递出微紧、指尖相触释放、收回定格余韵；景别由近景递出→近景微推接过→特写定格道具，一次无声的关系确认弧线。` | 道具交接、动作链 |
| 高潮段（重锤 + 留白） | `节奏自对峙静默、[关键动作]留白、[收束动作]落下重锤；景别由中景→特写→近景→特写门扇收束，全片最高点的留白曲线。` | 全片唯一重锤段 |

- 例（10s 单段 5 镜，高潮段）：`节奏自静置起步、中段回稳、按键处落下重拍；景别由全景（Wide）收进特写（Close-up）再拉回全景，形成一次闭合的情绪弧线。`
- **不要**把弧线写成长段落——它只在 `detailed_description` 段首占一行，作用是给整段定调，不是逐镜解说（逐镜设计理由仍留在分镜表，不写进提示词，见 directing_bridge 第 3 节）。

### ⑦ 空间舞台站位与机体朝向解耦（Spatial Stage & Body Decoupling）

**血的教训（售货机背反事故）**：写「背对镜头站在售货机前」，在平移或移动机位下，H3 会把「背对镜头」理解为优先级最高的状态，导致角色直接**背对着售货机**！
**核心原则**：角色机体朝向、摄影机机位视锥、环境交互目标是**三套独立的几何系统**，严禁混为一谈。

1. **三维解耦系统**：
   - **世界空间参照（World Frame）**：环境中的绝对方位（东/西/南/北、路中央、废墟右侧残垣）。
   - **交互目标向量（Target Vector）**：角色与道具/环境的几何相对关系（正对售货机投币面板、与柜机中轴夹角 0°）。
   - **摄影机视锥关系（Camera Relation）**：摄影机所处的观察方位（侧平移、后背略偏左侧入画、正侧面机位）。
2. **正向三联描述句式（必写）**：
   - 严禁单独出现「背对镜头」或「面对镜头」这种无交互锚点的模糊指令！
   - **规范句式**：`机体站位于[屏幕/空间坐标]，正面躯干朝向[交互目标]，后背呈[N度]夹角迎向[机位视锥]；角色视线100%锁死在[目标物件]，与机位视锥绝无眼神交互。`
   - *例*：`机体站位于画面右三分之一处，正面躯干朝向正东偏北15度的售货机控制面板；后背呈45度迎向正西侧缓慢右移的摄影机（背朝视锥，面对目标）；机体与售货机前面板保持30cm操作间距。`

### ⑧ 视线与传感器锁定（Anti-Lens Gaze Locking & Anti-Dead-Eye）

**问题本质**：生成模型对人脸/面部传感器有极其强烈的「正面肖像注视机位（Looking directly at camera）」先验偏好。一旦不锁视线，角色会不由自主地转头偷看镜头（出戏穿帮）或眼珠呆滞死盯虚空（死鱼眼）。

1. **Anti-Lens 强制声明**：
   - 凡非对镜独白镜头，必须在神态或防错约束中显式加入**视线脱钩指令**：
   - `光学视轴/眼球焦点全程绝对钉死在[具体部件/道具/地面]，严禁直视镜头，严禁向机位视锥投射视线。`
2. **视线与头部的生理/物理联动**：
   - 视线变动必有头部偏角补偿（Pitch 俯仰 / Yaw 偏航 / Roll 翻滚）：
   - *人类/仿生人*：`视线沿操作台缝隙自左向右扫动5cm，下颌微抬3度，眼球微转而颈椎保持不动，目光绝不漂向摄影机方向。`
   - *机械体*：`头部水平偏转15度将主光学传感器对准出货舱门，俯角下倾20度，光轴垂直投射在金属锁扣上，机位视锥处在传感器盲区。`

### ⑨ 转向动力学闭环与运动矢量（Pivot Kinematics & Kinetic Trajectory）

**禁止**：只写「他转身走向……」或「机器人转身」。模型会给出毫无重心的全身整体旋转或下半身瞬移。
**改写（三阶物理转向闭环）**：
1. **行进与减速（Linear Deceleration）**：前序运动向量刹停，重心转移；
2. **轴心旋转（Pivot Rotation）**：以接触面为支点（左脚掌/单侧履带），指定明确转向角度（顺时针/逆时针 N 度）；
3. **随动锁定（Kinematic Chain & Locking）**：骨盆/底盘先转 → 躯干跟转 → 头部与视线最后就位并锁定。

| 别写 | 规范写法 |
|---|---|
| 转身面向售货机 | 行进惯性减弱刹停在路边，以右脚底板为旋转轴心，躯干逆时针回旋80度，左脚向外横跨半步踩实地面稳住重心，正面最终完全对准售货机面板，双臂自然下垂呈操作准备态。 |
| 机器人转头走开 | 头部主传感器先逆时针偏转45度望向街道深处，底盘驱动轮输出制动微颤，随后以右侧履带为支点原地差速旋转60度，躯干跟进对齐行进方向，向前直线加速驶离，背影逐渐变小。 |

### ⑩ 无五官机械体/特殊角色物理微表情规范（Mechanical Micro-kinetics）

**适用对象**：机器人、机械臂、戴全盔装甲、外星构造体等无人类五官表情的角色。
**问题**：无法套用人类面部肌肉分解，导致机器人宛如死石或呆滞玩具。
**微表情动力学四大组件**：

1. **光学传感器微动态（Aperture & Focus Dynamics）**：
   - 光圈叶片收放：`主眼光学镜头内部机械光圈每2秒缩放微调0.5mm，模拟自动测距变焦；`
   - LED 指示与频闪：`状态指示灯以1.5Hz频率微弱呼吸闪烁，故障时伴随0.1秒的阶跃式熄灭；`
2. **头部几何姿态角（Head Posture Euler Angles）**：
   - 偏航（Yaw）、俯仰（Pitch）、侧倾（Roll）的定量微调：`头部向右微侧倾3度（Roll 3°），呈信息扫描态；随后下颌下潜5度锁定目标。`
3. **关节与伺服液压颤动（Servo Jitter & Hydraulic Micro-stroke）**：
   - 机械负载微动：`颈部液压推杆微退1.5mm，伴随金属接缝处高频极细微震颤（幅度<1mm）；机械抓手三指指尖微张5度保持受力待发态。`
4. **表面风蚀与散热次级动效（Thermal & Surface Kinematics）**：
   - 散热格栅排出微量热扰动气流；外挂线缆与管路因机体微颤产生周期性摆幅（频率1Hz，幅度2mm）。

### ⑪ 电影级高级镜头语言与调度技法库（Cinematic Mise-en-scène & Camera Tactics）

单纯的平视定焦镜头会让画面沦为监控录像或静态插画。根据镜头叙事目的，必须主动调度以下高阶视听语言：

#### 1. 双人/多主体正反打越肩（Shot-Reverse-Shot Over-The-Shoulder / OTS）
- **适用场景**：两人对话、对峙、交易、情感试探。
- **180度轴线法则（180-Degree Rule）**：机位始终保持在主体关系连线的同侧，严禁跨轴导致视线对撞穿帮。
- **构图规范**：前景角色的后脑勺与肩线（OTS Frame）呈严重失焦状态，占据画面左侧或右侧的 15%-25%，为中景受访主体提供深度参照与压迫感。
- **范例句式**：
  > `镜头：硬切至过肩近景（OTS Shot, 85mm），机位在<Subject 1>右肩后40cm处；其右肩与后颈轮廓微虚遮挡画面右下角（约占画幅1/5）；焦点清晰落在中景正前方的<Subject 2>面部；两角色视线严格沿180度轴线形成眼神对咬。`

#### 2. 前景虚焦遮挡与深度构图（Foreground Occlusion / Dirty Frame / Framing in Depth）
- **适用场景**：废墟探索、潜行、孤独感、窥视感、空间建立。
- **核心逻辑**：在摄影机与角色之间有意识安插自然环境杂物（如锈蚀工字钢柱、破损门框、下垂电缆、机械仪表盘、雨刷器水滴）。
- **构图规范**：前景物体**极度虚焦（Heavily Blurred Foreground）**，成为“天然框景（Framing within a Frame）”，打破单薄的 2D 贴图感，制造强烈的电影沉浸与临场窥视感。
- **范例句式**：
  > `镜头：前景左侧有一根斑驳生锈的铁管道（严重失焦，占画面左侧三分之一，形成天然框景）；机位透过管壁与破损砖墙的缝隙，锁定中景3米外正半蹲检修的机器人，背景废墟建筑呈柔和渐晕散景。`

#### 3. 焦点转移（Rack Focus / Focus Pulling）
- **适用场景**：因果揭示、注意力转移、内心震动（从动作道具揭示到角色神态，或从说话者移至倾听者）。
- **构图规范**：指明转移时长与起点/落点，伴随平滑光斑弥散。
- **范例句式**：
  > `镜头：浅景深固定机位；第1.2秒，焦点通过 Rack Focus 在0.6秒内由前景指尖紧握的齿轮零件平滑拉至后景伙伴机器人的主光学单眼上；齿轮随之化为边缘柔和的浅蓝散景光斑。`

#### 4. 视角高度心理暗示（Camera Angle Psychology）
- **微俯角（High-Angle 15°-25°）**：强化角色的孤独、疲惫、受制于环境或微小无力感（如雨中候车亭孤独蜷缩）；
- **微仰角（Low-Angle 15°-25°，仰拍）**：强化主体的崇高感、威慑力、机械骨架耸立与坚毅意志；
- **贴地视角（Ground / Worm's-Eye View 5-10cm）**：机位几乎贴地，前景突出履带碾压碎石或雨鞋踏溅泥水的微观冲击，背景拉伸地平线。

### ⑫ 光学摄影物理参数量化（Optical Optics & Depth of Field）

拒绝含糊的“远景/近景”，在每拍 `镜头：` 行中引入标准工业级光学焦段与光圈参数：

| 等效焦段 | 景深与光圈 | 视觉效果与心理感受 | 适用镜头 |
|---|---|---|---|
| **24mm - 35mm** 广角 | f/8 - f/11 深焦（Deep Focus） | 空间纵深拉大，边缘轻微透视张力，从前景地表到无限远背景全锐利 | 大全景空间建立、荒原行进、废墟宏观扫描 |
| **50mm** 标准镜头 | f/2.8 - f/4 自然景深 | 最接近人眼自然透视，无畸变，客观纪实感 | 中景全身互动、行进跟拍、常规叙事交代 |

### ⑬ 动作两端动力学：动势预备与惯性回弹（Anticipation & Overshoot）

机械与生物都不是刚体。动作绝不能“突然从0跳到100”或“突然刹死焊在终点”：

1. **动势预备（Anticipation，反向蓄力）**：
   - 任何主要肢体发力前，必然先产生反向微小形变或位移：
   - *例（抬手按键）*：`手腕在向前伸出前，肘关节先向后微缩5mm、小臂微下沉蓄力，随后才平滑前推；`
   - *例（迈步启程）*：`骨盆在迈步前重心先向后脚下压2cm，前脚尖微翘蓄势，随后躯干前倾顺势迈出。`
2. **惯性回弹与超调（Overshoot & Settle，动量缓冲）**：
   - 动作到位刹停瞬间，肢体末端产生物理性微小冲过头（Overshoot）与弹性回摆（Settle）：
   - *例（机械臂抓取）*：`机械爪在紧扣阀门的刹那，金属指节受反作用力轻微震颤反弹0.5mm，液压杆瞬间受力微阻尼缓冲后彻底锁死；`
   - *例（转身刹停）*：`外披风衣衣摆在机体完全转正后，因惯性继续向前甩动3cm，随后向后回摆两次（周期0.4秒）归于静止。`

### ⑭ 口型物理发音预备与收束（Phonetic Anticipation & Lip-Sync Dynamics）

根绝“假唱、吞字、台词完了嘴还在蠕动”的音画脱节问题：

1. **发音前 0.15 秒预备态（Phonetic Anticipation）**：
   - 在台词 `<d>` 标签对应的动作描述中，显式声明：
   - `在第一音节发出前0.15秒，下颌微微下沉2mm，双唇微启呈对应元音口型，胸腔与喉结可见微位移；`
2. **发声期间唇齿动态（Vowel-Consonant Modulation）**：
   - `台词发音期间，双唇随音节开合自然，幅度适中（张合间距3-6mm），牙齿隐约可见，喉结随声调上下轻微滑移；`
3. **句尾收束与锁闭（Terminal Crisp Settle）**：
   - `末尾音节收束瞬间，嘴唇利落闭合复位，下颌回位，严禁台词结束后仍有无意义的面颊抽动或蠕动。`

### ⑯ 物理惯性延续与跨台词双轨多任务演出法则（Momentum Preservation & Multi-Task Performing）

#### 1. AI 视频“说话即立正”木偶痼疾（Talking Freeze Syndrome）的本质根因
在基于扩散与 Transformer 的文本到视频模型中，当解析到 `<d>` 台词或“说话/发声”描述时，文本-视频交叉注意力（Cross-Attention）会瞬间把大量的权重集中分配在人物面部、唇齿与咽喉区域。导致的结果是：**角色原本正在行进的步伐、作业中的双手或身躯的物理动量被系统瞬间忽略清零，直接退化为原地立正不动的“站桩假人（Talking Head Doll）”**。

#### 2. 核心铁律：动量延续与双轨多任务（Dual-Track Performance）
**除非剧本特意说明“角色停下脚步、站定对峙说话”，否则所有角色在说话发音时，必须严格保持并延续先前的物理动作与机械惯性。**
角色必须一边说话、一边持续执行下半身行走或手头作业，形成视觉与听觉的双轨多任务。

#### 3. 强制语法结构：台词与下半身动量强制捆绑（Hard Binding）
在台词 `<d>` 标签之后，**绝不能只写空洞的情绪或任由动作留白**，必须紧随「这句话说出时，……」的句式，强行注入下半身或肢体作业的物理位移指令：

```
画面：<Audio 1> (S1) 说（实声、送气少｜语速适中）：
<d>台词内容</d>
这句话说出时，<Subject 1> 保持行进动量向前迈步未停，双脚以0.6m/s速度交替踩踏地面，身躯重心顺应步频平稳起伏（垂直振幅2cm），双臂顺应惯性自然前后摆动，头部仅微偏10度，严禁在发声时身躯骤停立正。
```

#### 4. 三大高频伴随动作模式库

| 伴随模式 | 适用场景 | 工业级动力学写法范例 |
|---|---|---|
| **边走边说（Walk-and-Talk）** | 角色并排行进、长廊行进、穿越荒原 | `这句话说出时，机体行进动量毫无衰减，双足交替迈步步伐未停，脚掌每一次触地均扬起微小沙尘，身躯重心保持 0.6m/s 线性向前平移并伴随微小起伏，双臂随步频前后自然摆动，视线向前平视锁定前方路径。` |
| **边修/边干边说（Busy Hands / In-Action）** | 维修、检修、操作终端、搜寻包裹 | `这句话发出时，机械抓手对螺栓的紧固旋拧动作毫不停顿，手腕伺服电机微弱咬合振颤，指节受力压紧金属外壳，身体重心持续向前微倾下沉，仅头部主光学传感器微扬15度。` |
| **边巡边说（Scanning-while-Moving）** | 侦察、夜间巡逻、机器人在暗处探索 | `这句话说出时，底盘履带/双足保持匀速滑行平移，前照主灯在地面维持每秒 30 度的扇形往复扫荡，头部在行进中独立偏航转动，形成身躯向前、视线巡视的运动解耦。` |

#### 5. 动量保护否定约束（Momentum Preservation Constraint）
在包含台词的节拍中，动作描述末尾或正文末尾防错约束中，**显式加入动量保护禁令**：
> `防错约束：严禁发声时机体骤停立正，行进/作业物理动量全程线性延续，杜绝"开口说话即冻结在原地"的AI木偶停滞（No freeze-on-talk）。`

#### 6. 多主体不对称动力学脱耦（Asymmetric Movement Decoupling）
当画面中同时存在多个主体（如两人同行、或一人说话一人工作）时：
- **听者绝不是蜡像**：未发声的角色必须拥有独立的物理交互，如低头确认线路、调整背负装备的带扣、伺服电机 1-2 秒一次的自检微颤、或随风微动的风衣衣摆；
- **禁止全员同步停滞**：绝不允许说话角色开口时，听者也同时石化停滞。双方物理轨迹各自独立推进。

### ⑰ 起镜：空间先立、运镜后启（Opening Shot & Camera Ramp）

> **来源**：`h3-cinematic-prompting` 的「硬切实景起镜 + 前 0.5s 静止」。**口径已按本管线实测修正**（位移式运镜服从度低、175 帧段预算紧），属【建议项 v2.6】。

**问题**：段首第一拍直接写"两人从左侧走入中庭"，模型手里没有可锚定的空间，只能把参考图当首帧糊上去——开镜第一眼就是贴图感。

**三步，按顺序落在 `[节拍 1]` 内**：

1. **空间锚点先行**：`镜头：` 之后的第一句点名**三样可读的静态物**——背景骨架（残破透光顶 / 扭曲扶梯钢架）、地面材质与反光（浅积水、水泥接缝）、光的落点（冷灰天光斜切在地面哪一块）。不要写"环境很破败/氛围压抑"这类总结词。
2. **构图先稳住 0.3-0.5 秒**：写成**正面描述**——「第一拍前半段画面构图保持完全一致，只有尘粒缓慢漂移」。**不要写"固定机位零位移""镜头不动"**：否定式服从度低（§二 末），而且容易反向诱导推镜。
3. **运镜匀速启动**：`随后机位以[幅度 + 速度]缓慢[摇 / 仰 / 横移]`。只写**角度变化类**运镜；推/拉/移（位移式）服从度低，能不写就不写（SKILL.md §4.1）。

**适用边界（比原技能收得更紧）**：

- **只在段的第一个镜位用。** 段内第 2 镜起不再重复静置——175 帧≈7.3s 装 3-4 镜，每镜静置 0.5s 就要吃掉 20% 预算。
- **续接段不写「硬切至全景」**：段首帧已被钉帧锁定，起镜写成「从上一段尾帧的状态出发，构图保持…」；硬切交回**段内第 2 镜**。原技能"每个镜头都硬切"的写法只适用于段内换镜。
- 单镜时长不因起镜压到 1.5 秒以下（§二 末），否则画面来不及建立会闪。

| 别写 | 写成 |
|---|---|
| `[节拍 1] 画面：两人从左侧涉水走入中庭` | `[节拍 1] 镜头：硬切至中庭全景，机位平视；画面右侧残破采光顶漏下冷灰天光，斜切在画面下方浅积水面上，积水倒映扭曲扶梯骨架；第一拍前半段构图保持完全一致，只有水面浮尘缓慢漂移；随后机位以中等幅度、慢速向左横摇，装得下整座中庭的高度。` |

> 表内示例是**全片第一段 / 无续接的独立段**。**续接段**把开头那句「硬切至…全景」换成「从上一段尾帧的[姿态/位置]出发」，其余三步（锚点→稳构图→角度式启动）不变。

### ⑱ 跨镜动作接力：提前量与顺接（Action Hand-off）

> **来源**：同上，属【建议项 v2.6】。**与 ⑬ 分工不同**：⑬ 管**一个动作内部**的蓄力（Anticipation）与回弹（Overshoot）；本条管**两个镜位之间**的动作交接。

**问题**：镜位之间动作断层——上一镜还在跑，下一镜已经站着，模型把两镜当成两个独立事件各自重开。

**三条要求**：

1. **上一镜末尾 1.0-1.5s 必须给出下一镜动作的起始态**：写「已经逼近转角边缘、身躯前倾、圆脑袋探出」，**不写「准备转向」「即将探头」**——"准备/即将"是意图词，模型会把它渲染成静止等待。
2. **同件接同件**：手接手、脚接脚、视线接视线。换主体接力时显式写谁停谁动（「<Subject 1> 停步，<Subject 2> 起步追赶」），不许让模型自己分配。
3. **下一镜开头复述一次**：`接上一镜` + 该姿态一句话（「<Subject 2> 仍保持探头张望姿态」）。不复述，模型会当作新事件重开，姿态也就重新抽一次。

**跨段时只传状态、不传叙事（v3.8 口径不变）**：接缝另一边只写姿态与位置，不复述上一段做了什么事。因果由剧本与裁头机制承担，提示词不负责复述。

**人工判据**：读段尾最后一句——如果它落在「停住 / 站稳 / 放下 / 转身站定」，而下一镜开头是移动，就是断层；段尾落在「逼近 / 前倾 / 半起 / 已探出」，下一镜开头是同向延续，才算接上。

### ⑲ 特写与独角戏的素材隔离（Ghost-Asset Isolation）

> **来源**：同上。本条是**素材纪律**而非建议项：参考图挂了谁，画面里就会长出谁，这是几何必然，与题材无关。

**问题**：单人特写里，画面角落莫名拼进另一个角色的脸或半截手臂。

**三条**：

1. **媒体架只挂本镜可见主体**：局部特写 / 微距 / 单人镜头，只挂该主体与本镜道具；画外角色的图**不要挂**。
2. **`subject_definitions` 不定义画外角色**：定义了就等于给了模型"这个角色在场"的许可，哪怕正文一个字没提。
3. **正文首句加防出戏约束**：`防出戏约束：本镜为局部特写，画面中绝无 <Subject 1> 的全身身影与面罩。`——点名编号，不写"其他角色/旁人"这种模糊指代。

**与 `权限=` 的分工**：`权限=` 管"这张图控制什么、不控制什么"；本条管"这张图该不该在场"。**先决定在场，再写权限。**

**自检**：把本段 `subject_definitions` 的 Subject 清单与正文出现的角色对一遍——正文没提的角色，不该有 Subject 行。

### ⑳ 六轨表演：情绪场景的物理外化展开（Six-Track Performance）

> **来源**：`h3-automated-pipeline` 的"人物六轨细腻情绪表演规范"（2026-11-06 并入），属【建议项 v2.7】。
> **与既有条款的关系**：三-① 管"禁情绪词、2-3 个可见动作"（硬项）；本条是**情绪重场的展开框架**——
> 当一拍要演"崩溃/对峙/克制到爆发"这类高浓度情绪时，2-3 个动作往往不够撑，按六轨逐条外化，
> 每轨一条物理描述，避免漏轨变成"只有脸在演"。

**触发条件**：节拍涉及①情绪波动（喜悦/悲伤/愤怒/恐惧/犹豫/崩溃/释怀…）②戏剧对峙/试探/对视 ③含 `<d>` 台词的发声状态——任一满足，就按六轨过一遍。

**查表入口（emotion_performance 库，v2.7 并入）**：写情绪重场前，拿剧本里的情绪触发词查
`references/emotion_performance.md`：

- **单一情绪**（如"震惊""悲伤哭泣"）→ §B 40 条白话表演库逐条对应（目瞪口呆/无声落泪/嚎啕大哭/抽泣哽咽…），每条给六轨分解 + 强度边界 + 速用句；
- **先后转换**（如"先震惊后崩溃"）→ §A 决策层"先后转换"定每拍强度档，再查 §C 十组转换组合（隐忍→爆发、委屈→哽咽→重新克制等同型范例）；
- **相似情绪易混**（惊讶 vs 惊恐、忧郁 vs 麻木）→ §A 相似情绪区分节。

**使用纪律**：① 库里的呼吸/抽气描述按该库头部"H3 适配口径"映射表降级成位移，声音进表演括号/音效行；
② 速用句拆成纯物理描述再用（比喻/剧情词会被 preflight 拦）；③ 每拍只挑 2-3 轨，六轨全上是菜单当清单必超载；
④ 多段哭戏的泪痕/红眼眶等渐进状态，下一段正文要独立复述（钉帧不锁表演）。

**六条轨道与 H3 安全写法（人类 / 无五官机械体双模）**：

| 轨道 | 人类/写实生物 | 无五官机械/载具等价映射 |
|---|---|---|
| ① 眼神 | 视线锁定目标、眨眼频次、从闪躲到对视的焦点转移 | 双主镜头光圈缩放对焦、指示灯 2-4Hz 频闪、视轴绝不偏向镜头（接三-⑧） |
| ② 面部 | 眉弓压低、眼眶紧绷、咬肌抽动、鼻翼微翕、嘴角下扯 | 散热格栅微开合、面甲滑轨微移、车灯明暗呼吸变频（接三-⑩） |
| ③ 头肩 | 下巴内收(防御)/微仰(傲慢)、肩膀骤紧耸起或脱力塌陷 | 头部偏航 15°、颈部液压杆微动、肩部装甲闭锁（接三-⑩姿态角） |
| ④ 手部 | 指尖发白攥紧衣角、指节摩挲道具、掌心微颤展开 | 机械夹爪开合微颤、缆线瞬间绷直、指节伺服微调 |
| ⑤ 身体重心 | 重心后撤 5cm(警惕)/前倾(压迫)、脚跟顿挫刹停、膝盖微屈 | 悬挂下沉、履带/轮组制动反馈、底盘绷紧定格（接三-⑨转向闭环） |
| ⑥ 声音 | **见下方口径修正**——文本里只写位移，声音进台词表演括号 | 柴油机怠速变调、气阀短促排气——同样只写**事件型短拟音**进 `音效：` 行 |

**⚠️ 第⑥轨口径修正（本管线实测，压过原规范）**：原规范第⑥轨写"倒吸冷气声、屏息 2 秒、粗重鼻息、
喉头吞咽、台词带颤音"。**呼吸/喘气/吞咽类描述写进画面文本会被 H3 当成发声指令**，真的生成呼吸声，
挤掉段尾留白导致整段重抽（实测见三-① 警告框）。落地写法：

- **画面文本**：只写看得见且不出声的位移——「喉结上下走了一次」「胸口起伏改为肩背保持不动，只有
  每三到四秒一次眨眼」；「倒吸冷气」改成「双肩骤然上提 1cm 随即沉下」；
- **声音层**：台词的颤音/气声/哽咽写进 `<d>` 前的**表演括号**（「气声为主、送气不稳、尾音下沉」），
  不进画面描述；纯拟音（一次短促的鼻息）若剧情必需，写成 ≤0.4s 的**离散短点**进 `音效：` 行并封口。

**表演因果闭环公式**（排拍顺序参考，来自原规范）：

```
[外部事件刺激] → [第一反应：眼神顿挫/光圈骤缩] → [肌肉/零件级外化：头肩+咬肌+手指收紧]
→ [意志性决策：强行压抑平静 / 决然转身 / 破防泪崩]
```

**示例**（"压抑悲痛"一拍，六轨全落）：

```
画面：<Subject 1> 视线钉死在地面碎裂的怀表上，眨眼频次降为零（①眼神）；
眉心锁拢，右侧咬肌抽动两次，下唇微颤泛白（②面部）；
头部向后微抵墙面，下巴内收（③头肩）；
右手五指抠进砖缝碎灰，指节发白（④手部）；
重心后撤靠死墙面，左肩微塌右肩耸起（⑤身体）；
双肩骤然上提 1cm 随即沉下（⑥第一反应位移，声音进台词括号）。
<Audio 1> (S1) 说（气声为主、声带闭合不完全、尾音下沉）：<d>Why didn't you tell me?</d>
```

## 四、声音规范（v2 核心改动）

### 4.1 声线卡：`<Audio N>` 是文本声锚，不是音色克隆

H3 房规用 `<Audio N>` 描述音色，**纯文本**（素材架 audios 槽留空也能生效）。全片同一个角色必须**逐段原文复制同一张卡，一字不改**——这是跨段声线一致的唯一手段。

卡片注册表：`scripts/voice_card.json`。卡里两套字段：
- `prompt_text` — 写进提示词的文本（**只写感知描述，不写 Hz**，H3 对数字不敏感、对"尖/亮/低/气声"敏感）
- `qa.target_f0 / f0_tol` — 只给我的自检脚本用，不进提示词

写法（对齐 H3 官方示例的语域）：

```
- <Audio 1> 为 <Subject 1> 穗 (S1) 的声线锚定：14岁东亚少女音质，音域偏中低、不尖不亮（近似成年女性偏低音区），弱声气声发声为主，送气少、气息浅；语速偏慢，咬字清晰不做夸张起伏，句尾自然下沉不上扬；日语原声，无哭腔无颤抖无喊叫。
```

### 4.2 台词：`<d>` 标签 + 表演括号

```
<Audio 1> (S1) 说（气声为主、送气量低｜语速慢，重音落在"何"，尾音不上扬）：
<d>これは、何？</d>
```

- 台词必须**原文照抄**，日语就是日语，不改写不翻译
- 括号里只写发声方式（气声/实声/送气量/语速/重音位置/尾音走向），**不写情绪词**
- 只写会说这台词的节拍，其余节拍显式写 `神态：嘴唇闭合，无发声`

### 4.3 台词落点（防截断）

一采有「音频按画面尾部截断」行为，**台词结束必须距段末 ≥1.0 秒**，段首留 ≥0.3 秒起手。
10 秒段的安全区：`0.3s ~ 9.0s`。排节拍时先算台词时长，再倒推动作时长。

**粗估公式**（气声慢速日语，`check_prompt_v2.py` 用同一套）：`假名 0.20s/字 + 汉字 0.26s/字 + 标点 0.12s + 0.10s`。
例：「私は、なぜ、これをやっている？」≈ 2.9s。单句必须 ≤ 段长 − 1.3s。

**实测（seg13 v2.1，4 次重抽）**：H3 对「约 5.4-7.6 秒」这类秒数描述不敏感，4 次里 2 次把末句台词拖到 9.7s+ 贴尾。对策：
- 末句台词尽量放在**节拍中段**而非节拍结尾，并写「在本节拍前半段发出」
- 防错约束里加一条「第二句台词必须在 X.X 秒前结束」
- 音频自检不达标就换 seed 重抽——台词落点是概率性的，与床音一样靠筛选不靠指令

**硬规则（v2.2 实战补充）：默认一段一句台词。**

| 段内台词数 | 结果 | 建议 |
|---|---|---|
| 1 句 | 稳定（seg21a/21b/22/23a/23b 均一次过） | 标准写法 |
| 2 句 | 3 次里 2 次末句贴尾（seg23 实测 9.42/9.66/9.65s） | **拆成 a/b 两段**，各放一句 |
| 3 句以上 | 必拖尾 | 必拆 |

拆段时台词放在**第 1 拍文本最前面**（不是"第 2 拍"——实测第 2 拍会差 0.3 秒以上），句后留两拍静默动作。详见下面 4.3.1。

### 4.3.1 台词块的位置梯度（175 帧段实测四版）

台词想在什么时候响，**文本上就必须排在那个位置之前**。H3 完全忽略秒数描述，只认文本事件顺序。

| 台词块位置 | 实测结果 |
|---|---|
| 写在动作串**之后**（"直起身、擦手、走出棚、走三步、停、抬手，然后开口说"） | **完全没生成** —— 语声 0 个，该时段无任何事件 |
| 第 3 拍文本最前 | 7.07s 说完（距段末 0.23s，不够） |
| 第 2 拍文本最前 | 6.64s（距段末 0.66s，还差 0.34s） |
| **第 1 拍文本最前** | **5.09s（距段末 2.21s，PASS）** |

**正确结构**：每一拍里，`<Audio N> 说（…）：` + `<d>台词</d>` 必须排在**该拍所有动作描述之前**，
动作串整块挪到 `<d>` 之后，写成「这句话说出时，他正……」。例：

```
[节拍 2] 镜头：……画面：<Audio 2> (S2) 说（实声、送气少、音量小｜语速慢…）：
<d>上水管。</d>
这句话说出时，<Subject 3> 正从左门里出来、右脚踩在铸铁踏板上……
```

**为什么不能只挪到第 2 拍**：前面几拍的文本量已经把时间吃掉了，H3 按顺序排完才开口，
前面越满、台词越晚。放第 1 拍最前，等于给了它最大的提前量。

**附带好处**：台词提前后常能把"因果更紧"的表演带出来。比如让配角在车还没停稳时就开口，
正好贴合「没有寒暄，第一句就是零件名」这类写法——比让他走过来再说话更有劲。

### 4.4 三层声音：床音清零，拟音保留（v2.1 修正）

H3 把「对白 + 拟音 + 环境音」烘焙在同一条音轨里，无法分轨。所以只能在提示词里把**三类声音分开点名**，让模型知道哪些该有、哪些不该有：

| 层 | 典型内容 | 处理 | 理由 |
|---|---|---|---|
| **对白** | 穗的台词 | **保留** | 唇形依据 |
| **动作拟音** | 脚步、布料摩擦、珠子落进石槽、手掌拍上石座、绳结收紧 | **保留**，但单个 ≤0.5s、随动作起止 | 段内事件，不跨段延续就不破坏连续性 |
| **持续床音** | 风声、沙粒持续摩擦、空间长混响、低频音乐垫、心跳 drone | **清零** | 每段各自生成的床音必然不同，拼接 100% 断层 |

**关键认识：去「连续性干扰」≠ 全静音。** 床音是唯一真正的连续性杀手（它一直在响，接缝处两段床音对不上，耳朵立刻听出剪辑）；拟音是段内的点状事件，它在段内结束，接缝两边本来就该安静。所以拟音应当保留——它还是画面真实感的一半。

写法：

```
overall_soundscape:
只保留三类声音，其余一律不生成。
① 对白：<Audio 1> (S1) 的两句日语台词（第一句约3.0-3.9秒，第二句约5.4-7.6秒）。
② 动作拟音：脚步（干沙闷响）、拉绳结与收结的布料摩擦、琥珀珠落入掌心的轻碰、指尖按结的轻响——
   只在对应动作发生的瞬间出现，单个不超过0.5秒，动作结束即止，不延续不拖尾。
③ 对白与拟音之间的间隔为数字静音，不做"安静的房间底噪"。
禁止：背景音乐、音乐垫、低频drone、风声、沙粒持续摩擦、空间混响与长尾、环境氛围音、心跳、远景鸟鸣，
以及任何持续铺底的声音。
non_diegetic_music:
禁BGM/字幕/水印/UI/Logo
```

**每拍的 `音效：` 必须逐条点名**（物件 + 动作 + 材质 + 时长），末尾用「仅此 N 类，无其他声音」封口：

```
音效：三步脚步（鞋底压干沙，闷而短，每步约0.15秒）；拉绳结的细响；琥珀珠落入掌心的轻碰一声；衣料摩擦。仅此四类，无其他声音。
```

- **不要写 `音效：无（后期添加）`** —— v2 曾这么写，结果模型既生成了不该有的风声，也没生成该有的珠子声（它只学会了"这里没有声音"）
- **不要给拟音加 `<…>` 标签**；标签会让它变成独立音源，音量失控
- **边界规则**：段首 0.4s、段尾 0.4s 内不放拟音起点。否则拼接时被硬切，或跨接缝延续
- **拟音必须写成离散短点，不能写「一串 / 持续 / 随…变稀」** —— 这类描述会被 H3 铺成整段床音，同时抬高床音电平、吃掉段尾留白。同一段实测对照：

  | 写法 | 结果 |
  |---|---|
  | 「旧轮胎在碎石上滚动的一串闷响（约1.8秒，随速度变慢而变稀）」 | 段尾留白 **0.07s** FAIL，床音超标 |
  | 「轮胎压过碎石凸起的两下闷响（每声约0.3秒）」 | 段尾留白 **0.66s** PASS |

  判据：每个拟音都要写明确时长且 ≤0.4s；「全程」「一直」「持续」这类词**不要出现在音效行里**（要表达持续，就写成一个更长的整体环境，放到 soundscape 的禁止清单去管）。

### 4.5 提示词层做不到时的兜底

H3 是生成模型，"床音归零"不保证。兜底两道：

1. `scripts/check_audio_seg.py`（v3 三层判定）— 一采落盘即测：
   - `床音电平`：每频点低分位反推的持续成分，要求 ≤ **-50 dBFS**
   - `动作拟音`：高出床音 10dB 且不低于峰值 -16dB 的短事件（<0.55s）计数，`--fx yes` 时要求 ≥1 个
   - `台词结束点`：距段末 ≥1.0s（防一采尾部截断）
   - `段尾留白`：最后事件到段末 ≥0.35s（防拟音被切）
   - `语声 F0`：与声线卡对比（仅警告，气声与低频垫会干扰估计）
2. `scripts/audio_gate.py`（床音抑制）— 只在**低能量帧**上估床音谱（避开对白，避免台词密集段把语声当床音减掉），逐时频点按 SNR 自适应过减：接近床音的狠减（alpha=6），显著高于床音的轻减（alpha=1，保护对白与瞬态）。实测拟音峰值损失 <1.5dB。

回归测试：`scripts/test_audio_gate.py` 用合成信号（47Hz 谐波垫 + 低通风声 + 脚步 + 珠声 + 语声）验证，床音可清到 -100dBFS 以下而瞬态跌幅 <2dB。

## 六、写完必过的 preflight

**先跑脚本，再人工补齐**（脚本覆盖下面标 ⚙ 的项）：

```bash
<venv python> scripts/check_prompt_v2.py --seg <段名>          # 查 prompt_v2.V2_SEGS
<venv python> scripts/check_prompt_v2.py --ov ov_<项目>.json   # 查覆盖配置里的全部段
<venv python> scripts/check_prompt_v2.py --scan .              # 盘点目录下所有 ov_*.json（重写进度总表）
```

⚙ 可自动判定 = 骨架齐全 / 节拍数与帧长 / 节拍编号 / `权限=` / 声线卡逐字一致 / 情绪词 / 每拍音效封口 / 静音节拍写法（FAIL）/ soundscape 四段式 / 台词时长预算与末拍风险 / 环境次级运动条数 / 水印约束 / **服从度边界**：位移式运镜（后拉/拉远/推近，FAIL）、穿窗运镜（WARN）、否定式景别指令（WARN）/ 末拍动作数 ≥4（WARN）/ [结尾状态] 是否为状态型死条款（WARN）。

**格式**
- [ ] 七段齐全，段名一字不改
- [ ] 每个 `<Subject N>` 都有 `权限=`；每个 `<Audio N>` 都有 `(Sx)` 落点
- [ ] 节拍覆盖全时长，不重叠不留空；有 `[结尾状态]`
- [ ] `overall_soundscape` / `non_diegetic_music` 两段都在

**内容**（⚙ 部分已由脚本判，人工只需补四层动力学与光照细节，以及 ⑰⑱⑲⑳ 四条新条款——它们不做机检）
- [ ] 情绪词清零（含"极轻地/茫然地/平静地"这类副词）
- [ ] 段首有 `情感弧线：` 一行（节奏骨架 + 景别走向，只写能量曲线不写情绪词，见三-⑥）
- [ ] 每个动作有四层动力学（主动/稳定/补偿/不自主）
- [ ] **一拍不超过两个动作**（四个动作挤一拍，会砍掉最不起眼的那个）
- [ ] **空间与朝向三维解耦**：机体绝对朝向 + 交互目标 + 机位视锥夹角写全，**严禁裸写孤立的「面对/背对镜头」**（见三-⑦）
- [ ] **视线与传感器锁定**：非对镜独白镜头已显式写入「严禁直视镜头/视线绝对钉死在[目标]」（防偷看镜头穿帮，见三-⑧）
- [ ] **转向动力学闭环**：转向动作写明「减速刹停 → 接触面轴心转向度数（顺/逆时针 N 度） → 随动与终态锁定」（见三-⑨）

- [ ] **物理惯性与双轨多任务**：发声时下半身行进动量或手头作业未停（边走边说/边干边说），显式禁止发声时骤停立正冻结（见三-⑯）
