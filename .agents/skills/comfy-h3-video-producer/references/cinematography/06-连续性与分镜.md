# 04 · 连续性与分镜

单镜写得再好，接起来散，段落就废了。这一层管的是**镜与镜之间**。

---

## 一、五条空间规则

### 1. 180° 线（轴线）
- **规则**：同一场戏里所有机位停在这条线的**同一侧**，不能越线。
- **效果**：A 始终看画面右，B 始终看画面左，观众的空间感不会崩。
- **越线会怎样**：观众突然觉得两人"换了位置"，需要一两个镜头才能重新建立方位——这时候戏已经断了。
- **提示词里怎么写**：不需要写"180 度"，写**朝向**：`A 面向画面右侧`／`B 面向画面左侧`。
- **对应索引**：GrokFilm 138

### 2. 30° 法则
- **规则**：同一主体连续两镜，机位夹角至少变 30°。
- **低于 30° 会怎样**：观众读成"跳帧/穿帮"，而不是"剪辑"。
- **实用做法**：要么换角度（平视→45°），要么换景别（中景→近景），至少变一样。
- **对应索引**：GrokFilm 139

### 3. 视线匹配 Eyeline Match
- 人看向画外，下一镜给到他所看的东西；**方向要对**（他往右看，下一镜的东西应从左侧入画）。
- 视线高度也要对：站着看、坐着看、躺着看，机位高度不同。

### 4. 动作匹配 Match on Action
- 在动作**中段**切：手抬到一半切下一镜从半空接住。比"动作做完再切"顺滑得多。
- AI 做法：两镜写同一个动作的不同阶段，取相近的帧位对齐。

### 5. 屏幕方向 Screen Direction
- 人物往右走，下一镜还要往右走。**反向＝观众以为他折返了**。
- 转场时若必须反向，中间加一个中性镜头（正面/静物）过渡。

## 二、景别递进

| 段落类型 | 递进方式 |
|---|---|
| 常规叙事 | 远景 → 中景 → 近景（一次跨一档） |
| 强调冲击 | 远景直接跳大特写（**故意越级，一部片用一两次**） |
| 揭示 | 先遮挡/背面/远景，逐步走近，最后给脸 |
| 结尾 | 近景 → 中景 → 大远景（人还给环境） |

**别做**：连续三个同景别。观众会疲劳，且容易看出是同一批生成。

## 三、对话覆盖（cover it like a real shoot）

一场对话戏的最小机位组：

1. **Master / 主镜头**（017）：一个全景交代所有人位置、空间关系。**先拍它。**
2. **单打 A**（中景/近景，平视）
3. **单打 B**（同焦段、同高度、同景别——两边的单打必须匹配，否则对切会跳）
4. **过肩 A→B**（019）与 **过肩 B→A**
5. **反应镜头**（143）：不说话的那个人。**反应往往比台词重要。**

竖屏做法：以单打为主，Master 只留一条短的立方位。

**AI 实操**：
- 一镜一个人说话，中景或近景；远景里的脸撑不住口型。
- 手别进对话镜头（说话时手部最容易变形），要给手动作就单独给一个插入镜头（014）。
- 切点选在**一句台词结束、一个反应、一个动作**上。

## 四、转场：五类，先定归属再写提示词

| 类别 | 谁来做 | 说明 |
|---|---|---|
| 1. 镜头内完成 | 生成 | 运动本身就是转场：拉出揭示、穿门推进 |
| 2. 遮挡切 | 生成 + 剪辑 | A 结尾被填满，B 开头同样填满。**写物理过程，不写"无缝"** |
| 3. 首尾帧桥接 | 生成 | 给首帧尾帧，让模型补中间。适合形变 |
| 4. 动机硬切 | 剪辑 | 动作切、出入画、砸切。蒙太奇的默认 |
| 5. 纯后期 | 剪辑 | 叠化、淡入淡出、J/L 切。**不要写进提示词** |

**配比建议**：30–40 秒的片子里，遮挡切与桥接当"重音"用 1–3 次，其余走硬切。

## 五、分镜表格式（交付固定用这个）

```
镜 3 · 12–18 秒 · "水汽起来"
镜头：低角度微距，机位在杯底，100mm 微距，f/2.8
为什么：颜色变化从杯底开始，所以相机从那里起
画面提示词：<完整一句，镜头句在前>
视频提示词：<一个运动 + 动作 + 速度>
当心：<这一镜最可能坏掉的一件事>
接点：<怎么交给下一镜>
```

### 一个填好的三镜示例（同一条 30 秒短片）

```
镜 1 · 0–6 秒 · "进场"
镜头：远景，24mm，平视，机位在门口
为什么：先让观众知道这是什么地方、人在哪
画面提示词：16:9，远景，24mm，平视，机位在门口向内；咖啡馆临街玻璃窗，晨光斜进来，吧台在画面深处，一个女孩推门而入，风把门上的铃带动；暖调，浅景深后景虚化；玻璃反光占画面左侧三分之一
视频提示词：相机固定在三脚架上不动，女孩从门口走向吧台，6 秒内走到画面中部停住
当心：门口逆光会让人脸全黑
接点：动作切——她伸手推门的那一刻切

镜 2 · 6–14 秒 · "落座与手"
镜头：中景，35mm，平视，过肩
为什么：从空间收进人物，建立她与吧台的关系
画面提示词：16:9，过肩中景，35mm，f/2；前景是吧台台面（虚），女孩在画面右侧坐下，双手放在台上，吧台后的人只露出手臂；窗光从左侧打亮她的侧脸
视频提示词：相机极缓慢向前推进，8 秒内从过肩中景推到近景，停在她放在台面上的手
当心：手部动作容易变形，别让她把玩东西
接点：遮挡切——吧台后的人端着杯子横穿过镜头，画面被杯身填满

镜 3 · 14–22 秒 · "杯子上桌"
镜头：低角度近景，35mm，机位贴台面
为什么：把杯子拍成主角，同时换景别换高度，观众不会觉得在原地打转
画面提示词：16:9，低角度近景，机位贴吧台台面略微仰拍，35mm，f/2；一只白瓷杯放在她手边，热气升起，杯壁挂着水珠，背景是虚化的她（只到肩）；晨光从背后勾出杯沿亮边；杯口越过画面上沿
视频提示词：相机固定，热气持续上升，8 秒内不移动
当心：热气容易被生成成浓烟
接点：硬切到片尾字卡
```
