# 09 · 附录：从成片反推机位（拉片用）

> **这不是主流程。** 主流程是 `01` 与 `02`：拿到剧本或提示词，正向设计机位。
> 这一份只在两种情况用：① 你要拉片；② 客户只给了参考片、没给剧本。


这一层是反向的：**画面已经在，判断它怎么拍的。**
判断依据只有四条可测线索，其余都是猜。

---

## 一、四条线索

| 线索 | 测什么 | 推出什么 |
|---|---|---|
| **人物占画幅比例** | 人物高度 ÷ 画面高度 | 景别 |
| **地平线与消失点位置** | 地平线在画面上/中/下；直线是否倾斜 | 机位高度、是否斜角 |
| **透视压缩与边缘畸变** | 背景是否被压近、直线是否弯曲 | 焦段 |
| **连续帧位移与背景视差** | 主体与背景的相对移动 | 运动种类 |

**同一帧只能判前三项，运动必须看连续帧。** 这是硬规矩。

---

## 二、景别判据（量化）

以"人物全身可见"为基准，量人物高度占画面高度的比例：

| 比例 | 景别 |
|---|---|
| ≤ 12% | 大远景 |
| 15%–40% | 远景 / 全景 |
| 40%–55% | 中景（腰以上） |
| 55%–75% | 中近景 |
| 75%–100%（头肩为主） | 近景 / 特写 |
| 只取局部（眼、手、物） | 大特写 / 微距 |

量法：截图后按像素量，不靠眼睛估。

---

## 三、机位高度判据

- **地平线在画面中部 ±10%** → 平视
- **地平线在上方**（看到大片地面/桌面/头顶） → 高角度俯拍
- **地平线消失或看不到地面，背景是天空/天花板** → 低角度仰拍
- **垂直线全部汇聚到画面上方一点** → 极仰（虫视）
- **画面里没有地平线、纯平面图案** → 俯拍正扣
- **画面里的竖直方向线是斜的** → 斜角（量倾斜角，一般 15°–35°）

---

## 四、焦段判据

| 现象 | 焦段 |
|---|---|
| 前景大、背景小，纵深被拉长，边缘直线外鼓 | 广角（14–28mm） |
| 透视自然，接近肉眼 | 标准（35–50mm） |
| 背景被"压"到主体后面，人脸显得平、好看 | 中长焦（85–135mm） |
| 前后景像贴在一起，人海被压缩 | 长焦（150mm+） |
| 直线明显弯曲成弧 | 鱼眼 |

**判不准时给区间，不给单值**（"广角到标准之间"比"24mm"诚实）。

---

## 五、运动判据

必须逐秒抽帧看：

1. **背景有没有横向位移** → 横移 / 跟拍
2. **主体大小有没有变** → 推 / 拉 / 变焦。**再看背景透视有没有变**：变＝推轨（相机真的走过去），不变＝变焦（焦距拉近）
3. **画面有没有旋转** → 摇（水平）、俯仰（垂直）、滚转（绕光轴）
4. **画面有没有不规则抖动** → 手持；平滑穿行无抖动 → 斯坦尼康
5. **主体大小不变但背景在拉伸/压缩** → 推轨变焦

---

## 六、抽帧命令（Windows 用 C:/ 正斜杠）

```bash
# 单帧（判细节直接上 2000px，别拿糊图下结论）
ffmpeg -ss <秒> -i "$V" -frames:v 1 -vf "scale=2000:-1" -pix_fmt yuvj420p out.jpg

# 连续帧（判动作必须用这个，fps=2~4）
ffmpeg -ss <起> -to <止> -i "$V" -vf "fps=4,scale=960:-1" frames/f_%03d.jpg

# 接触表（一次扫全段）
ffmpeg -i "$V" -vf "fps=1,scale=320:-1,tile=5x4" sheet_%02d.jpg
```

## 七、误判清单（血泪）

| 错误 | 正确做法 |
|---|---|
| 只看一张静帧就写"他睁眼/转身" | **动作必须看连续帧**，单帧只能判静止状态 |
| 拿低分辨率图硬判道具/文字 | 上 2000px 重抽。糊图上的"结论"十有八九是编的 |
| 从台词倒推画面（"他说忘了关火"→写"灶上坐着锅"） | 台词是声音，画面是画面，分别核 |
| 沿用上一版稿子的描述 | 旧稿不是依据，**只有帧是依据** |
| 用文件名推断内容 | 文件名会骗人（`end_*` 的帧可能属于开篇） |
| 判"焦段＝50mm" | 只能给区间；单帧无法唯一解出焦段 |
| 把后期效果当机位（暗角、调色、加颗粒） | 这些不改变机位，别混进机位结论 |

---

## 八、输出格式（机位表）

一条片子/一段戏，按镜列表：

```
镜 3 · 00:12–00:18
景别：中近景（人物占画幅 62%）
高度：平视（地平线在画面 48% 处）
朝向：四分之三偏右
焦段：中长焦区间（背景压缩明显，估 85–105mm）
运动：推进（背景透视同步变，判为推轨非变焦）
接点：动作切（手抬到一半切）
置信度：景别/高度 高 · 焦段 中 · 运动 高
```

**置信度必须写。** 判不出来的写"判不出"，不要凑。
