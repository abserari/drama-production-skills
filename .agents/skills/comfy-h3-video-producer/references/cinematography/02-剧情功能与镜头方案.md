# 02 · 从剧本到镜头方案

输入是剧本/一段剧情，输出是一张镜头表。这一份给流程，`01` 给情绪取值，`03`–`06` 给具体词法。

---

## 一、先把剧本拆成 beat

**beat ＝ 一场戏里"关系或信息发生变化"的最小单位。** 没有变化的段落，进不了镜头表。

拆法：拿一支笔，在剧本上标出"从这里开始，观众知道了新东西"或"从这里开始，两个人的关系变了"。每个标记之间是一个 beat。

一场 30 秒的戏，通常 2–3 个 beat；超过 4 个，说明你想说的太多，删。

**一个 beat 只给一个情绪**（查 `01` 的表）。

---

## 二、八种 beat 与镜头配比

| beat 类型 | 要完成什么 | 镜头配比（3–6 镜） |
|---|---|---|
| **交代** | 观众知道这是哪、有谁、什么时间 | 大远景/定场 → 中景（人）→ （可选）近景（脸） |
| **进入** | 角色进入这个空间，戏开始 | 远景（从外）→ 过肩/跟随 → 中景落位 |
| **揭示** | 观众看到关键信息 | 中景或近景（人物反应）→ **插入镜头**（那个东西）→ 近景（人物变化） |
| **对峙** | 两人立场对撞 | 中景双人 → A 单打 → B 单打 → （反应）→ 回到双人或破水平 |
| **转折** | 事情变了，情绪翻面 | 前一镜保持旧情绪（稳住）→ 转折镜用**唯一一次**破格（斜角/手持/推轨变焦）→ 新情绪的镜头 |
| **崩塌** | 撑不住了 | 近景 → 大特写（局部）→ 空镜/负空间 |
| **和解 / 释然** | 松开了 | 中景 → 拉开到远景（一个镜头完成） |
| **离开 / 收尾** | 把人物还给环境 | 中景 → 背影远景 → 大远景（人变小） |

**配比不是公式，是骨架。** 每个 beat 至少要有"给信息的一镜"和"给反应的一镜"——只给信息没有反应，观众不知道该有什么感觉。

---

## 三、排一场戏的四步

1. **写一句话**：这场戏要观众带走什么？（不是"两人吵架"，是"原来他一直知道"）
2. **拆 beat**：2–3 个，每个标一个情绪词
3. **定景别序列**：整场按"收紧"或"松开"排（`01` 第二节），保证相邻两镜不同
4. **补接点**：每镜怎么交给下一镜（`06`）

排完检查一句：**把镜头表按顺序念一遍，能不能读出一个情绪曲线？** 念不出，就是平铺。

---

## 四、完整示例：三行剧本 → 六镜方案

### 剧本
> 深夜，她回到空荡的出租屋。冰箱上贴着一张便签。她看完，把便签折好放进口袋。灯没开。

### 第 1 步 · 一句话
"她其实一直在等一个不会回来的人。"

### 第 2 步 · 拆 beat
- beat 1（空荡）→ 孤独
- beat 2（便签）→ 悬念 → 揭示
- beat 3（折好放口袋）→ 悲伤（克制）

### 第 3 步 · 镜头表

```
镜 1 · 0–5s · beat 孤独
镜头：远景，平视，24mm，机位在楼道尽头
为什么：先让观众知道"这里没人"，孤独靠空房间交代，不靠她的表情
画面提示词：16:9，夜景，远景，平视，24mm，f/4；一间没开灯的出租屋，楼道的光从门口斜切进来，
在地上拉出一道亮带；玄关的鞋架空着，客厅深处只有窗外霓虹的一点反光；画面左侧三分之二是空荡的客厅
视频提示词：相机固定在三脚架上，无位移；门口的光带里有一点点尘埃浮动
接点：动作切——她的影子先进入画面

镜 2 · 5–11s · beat 孤独 → 悬念
镜头：中景，略高俯视，35mm，背面
为什么：她背对镜头，观众看不见脸，只能跟着她的视线找——先把"她在看什么"藏起来
画面提示词：16:9，中景，略高俯视，35mm，f/2；她背对镜头站在厨房门口，深色大衣还没脱，
手机屏的光从下方打亮她的手；冰箱在画面右侧，门上贴着一张浅色便签，很小
视频提示词：相机固定；她抬起右手，6 秒内把手机放下
接点：视线匹配——下一镜给便签

镜 3 · 11–15s · beat 揭示
镜头：大特写，微距，100mm，正对便签
为什么：信息要看清，但只能看清一半——便签字迹刻意失焦一点，观众知道有字，读不全
画面提示词：16:9，大特写，微距，100mm，f/2.8；冰箱门上贴着一张浅黄色便签，
边缘微微翘起，字迹偏软（不锐），冰箱表面有细密的水汽和一道旧的划痕
视频提示词：相机固定，画面无运动
接点：动作切——她的手入画把它揭下来

镜 4 · 15–21s · beat 悲伤（克制）
镜头：中近景，平视，50mm，四分之三
为什么：不给她哭。悲伤给人看"忍住"的那一下，比哭更狠
画面提示词：16:9，中近景，平视，50mm，f/2；她低着头站在冰箱前，便签在手里，
拇指压着折痕压了一下；厨房只有冰箱门的缝光，脸上半明半暗
视频提示词：相机固定；她把便签对折两次，21 秒末塞进大衣口袋
接点：硬切

镜 5 · 21–27s · beat 收尾
镜头：远景，平视偏低，35mm，背面
为什么：不跟拍，让她自己走进黑暗里——观众留在原地看她离开
画面提示词：16:9，远景，35mm，f/2.8；她背对镜头往客厅深处走，身影逐渐融进没开灯的暗部，
画面上方只有窗外的一点霓虹，地面反射一条细光
视频提示词：相机固定；她走到画面深处停住，不再移动（不回头）
接点：黑场
```

### 第 4 步 · 自检
- 相邻两镜都换了景别或高度（远→中→大特写→中近→远）✔
- 情绪曲线：孤独 → 悬念 → 揭示 → 克制 → 收 → 空（在读得出来）✔
- 全场没有一次华丽运动（悲伤不需要运镜）✔
- 每镜都有接点 ✔

## 五、常见剧本问题 → 镜头解法

| 剧本问题 | 镜头解法 |
|---|---|
| 信息说不清（观众看不懂发生了什么） | 加**插入镜头**：手、物件、屏幕、门缝——一句话不用改，信息就到位 |
| 情绪起不来 | 把一个大景别镜头**拆成两镜**（中景 → 近景），让观众有时间进入 |
| 观众迷失方位 | 场戏开头补一个**定场镜头**；或在对峙前补一个双人镜 |
| 太平（没有节奏） | 换景别密度：连续三个中景改成"远-近-中" |
| 结尾没劲 | 最后一镜从近景拉到远景，把人物还给空间 |
| 太长（超过 30 秒单段） | 找遮挡切点（门、人、手、水汽）分成两段 |
| 两人对话但没张力 | 单打景别必须相等；谁先破（换景别/换角度）谁就输了气势 |

## 六、给客户/学员的交付形态

一场戏一页，按 `06-连续性与分镜.md` 的六行格式（镜头/为什么/画面提示词/视频提示词/当心/接点）。

**"为什么"那一行不能省。** 这是本技能与"给你一堆提示词模板"的区别：说不清为什么，学员下次还是不会。
