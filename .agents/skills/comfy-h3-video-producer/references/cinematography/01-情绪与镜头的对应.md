# 01 · 情绪怎么变成镜头

**这一份是全技能的核心。** 机位、焦段、构图、运动都不是风格选项，是情绪的物理形式。
很多人写提示词"很平"，根子不在词不够，是**没想清楚这一镜要让观众感觉到什么**。

用法：先判定情绪 → 查表取组合 → 用 `03`–`06` 的句式写出来 → 用 `07` 加成一句提示词。

---

## 〇、一条总纲

> **情绪 = 观众与主体的距离 + 观众相对主体的高度 + 观众被允许看多久。**

- 想让人**靠近**：缩短距离、降低高度差、减少运动。
- 想让人**疏远**：拉远、抬高、加遮挡。
- 想让人**不安**：破坏水平、破坏对称、让画面动得没有终点。

反过来说：任何一条"情绪没出来"的镜头，先问这三个量调对了没有。

---

## 一、十二种情绪 × 镜头处方

每格给的是**组合**，不是单选。落地时按"景别+高度+朝向+焦段+构图+运动"六项取用。

### 1. 压迫 / 被控制

| 维度 | 取 |
|---|---|
| 景别 | 中近景到近景（把人挤满，无处可退） |
| 高度 | 高角度俯拍，或**头顶压物**的平视（横梁、天花板、低矮门框） |
| 朝向 | 正面（被审视）或背面（被围困） |
| 焦段 | 中长焦（压缩，让人贴住背景） |
| 构图 | 主体被画框边缘切掉一部分；负空间在上方被填满 |
| 运动 | 极缓慢推近，或**完全固定**（不动才可怕） |

- **为什么**：空间被压到最小，观众和角色一起没有退路。
- **反例**：用广角＋大远景拍压迫——空间一大，压迫感全泄。
- **索引**：GrokFilm 013 高角度 / 007 大特写

### 2. 孤独 / 疏离

| 维度 | 取 |
|---|---|
| 景别 | 大远景或远景（人极小） |
| 高度 | 平视偏**略高**（俯视一点点，人就孤立了） |
| 朝向 | 背面，或侧面不看镜头 |
| 焦段 | 广角（空间撑得更大） |
| 构图 | 大面积负空间，主体压在画面一角；或用画框内画框把人框死 |
| 运动 | 极缓慢拉出，或彻底固定 |

- **为什么**：观众离得远，又没有别人入画——孤独是"构图里没有第二个人"造成的。
- **反例**：孤独场景给特写。特写让观众靠近，靠近就不孤独了。
- **索引**：GrokFilm 008 大远景 / 062 负空间

### 3. 亲密 / 信任

| 维度 | 取 |
|---|---|
| 景别 | 近景或特写（头肩，甚至只到眼睛） |
| 高度 | 平视或**略低**（略低让人放松） |
| 朝向 | 四分之三或侧面（正面对视太有攻击性） |
| 焦段 | 中长焦浅景深（85mm，f/1.8） |
| 构图 | 主体居中偏一侧，背景化开；前景可有一点点虚化遮挡（像隔着什么在看） |
| 运动 | 固定，或极缓推 |

- **为什么**：距离近＋景深浅＝世界只剩他们俩。
- **反例**：用广角近景拍亲密——脸会变形，亲密变滑稽。
- **索引**：GrokFilm 003 特写 / 063 浅景深

### 4. 紧张 / 危险逼近

| 维度 | 取 |
|---|---|
| 景别 | 中景或近景（要看清，但不能全看清） |
| 高度 | 平视，但**前景有遮挡**（门缝、栅栏、植物） |
| 朝向 | 背面或过肩（观众和角色看同一个方向） |
| 焦段 | 中长焦（窥视感） |
| 构图 | 主体不在中心，画面留出"那里有东西"的暗部 |
| 运动 | 手持微抖，或极缓慢横移（像有人在挪动视角） |

- **为什么**：遮挡＝视野被限制，观众开始替角色紧张。
- **反例**：把威胁直接拍清楚。看清了就不紧张了。
- **索引**：GrokFilm 010 手持 / 158 前景

### 5. 失控 / 崩溃

| 维度 | 取 |
|---|---|
| 景别 | 大特写（局部放大到失真）或极近景 |
| 高度 | 斜角＋手持 |
| 朝向 | 正面，直视镜头 |
| 焦段 | 广角近景（畸变），或鱼眼 |
| 构图 | 主体被切出画框，画面失衡 |
| 运动 | 手持明显抖动、快速甩、滚转；**或推轨变焦** |

- **为什么**：水平线没了，观众就失去了判断依据。
- **反例**：崩溃用稳定大远景——太体面了。
- **索引**：GrokFilm 004 荷兰角 / 231 推轨变焦

### 6. 权力 / 威压

| 维度 | 取 |
|---|---|
| 景别 | 中景，人物完整入画（完整才显得"稳"） |
| 高度 | **低角度仰拍**，机位在人腰部以下 |
| 朝向 | 正面，正对镜头 |
| 焦段 | 标准到中长焦（不要广角，广角显得滑稽） |
| 构图 | 居中，对称，人物占画面高 60–70% |
| 运动 | 固定；或极缓慢推近 |

- **为什么**：仰视＝观众被迫抬头，身体先服了。
- **反例**：给弱者用仰拍，会读成讽刺或滑稽。
- **索引**：GrokFilm 016 低角度 / 162 居中

### 7. 渺小 / 敬畏

| 维度 | 取 |
|---|---|
| 景别 | 大远景（人 ≤ 画面高 1/8） |
| 高度 | 高角度或航拍 |
| 朝向 | 背面 |
| 焦段 | 广角或标准，深焦（前后都清楚） |
| 构图 | 主体在画面下部三分之一，上方被巨物/天空占满 |
| 运动 | 极缓慢拉开或升高 |

- **为什么**：比例本身就是内容。人不重要，世界才重要。
- **索引**：GrokFilm 001 航拍 / 012 直升机

### 8. 希望 / 释放

| 维度 | 取 |
|---|---|
| 景别 | 从近景**拉开**到远景（一个镜头完成） |
| 高度 | 由高转平，或由平转略仰 |
| 朝向 | 侧面或背面（看向远方） |
| 焦段 | 标准到广角 |
| 构图 | 视线方向留出大片空间；光从前方来 |
| 运动 | 拉出 + 升起，或向前推进（走向光） |

- **为什么**：空间变大＝可能性变多；这是唯一允许"运动幅度大"的情绪。
- **索引**：GrokFilm 005 推轨

### 9. 怀旧 / 记忆

| 维度 | 取 |
|---|---|
| 景别 | 中景到远景（记忆总是模糊的） |
| 高度 | 平视，略高 |
| 朝向 | 四分之三、背面 |
| 焦段 | 中长焦，浅景深 |
| 构图 | 居中、对称；画框内画框（像透过时间看） |
| 运动 | 极缓慢、匀速；或固定 |
| 质感 | 暖调、低饱和、颗粒、暗角 |

- **索引**：GrokFilm 271 复古胶片 / 270 暗角

### 10. 悬念 / 未知

| 维度 | 取 |
|---|---|
| 景别 | 中景（给一半信息）或局部特写（只给细节不给全貌） |
| 高度 | 平视，前景遮挡 |
| 朝向 | 背面、剪影 |
| 焦段 | 长焦（看不清） |
| 构图 | 主体偏一侧，暗部占据画面 |
| 运动 | 缓慢横移扫过（像在找什么），或固定等 |

- **为什么**：观众知道"还有东西没看到"，就会继续看。
- **索引**：GrokFilm 036 剪影

### 11. 愤怒 / 对抗

| 维度 | 取 |
|---|---|
| 景别 | 近景，两人**同样景别对切** |
| 高度 | 平视（谁都不高谁一头）或**双低角度**（都强硬） |
| 朝向 | 正面/四分之三，视线对撞 |
| 焦段 | 标准（35–50mm），不要长焦压缩 |
| 构图 | 居中，人物顶满画框 |
| 运动 | 固定；切点密 |

- **为什么**：平等的高度＋相等的景别＝势均力敌。
- **反例**：一方仰一方俯，胜负就被构图提前判了。
- **索引**：GrokFilm 019 过肩 / 139 30 度

### 12. 悲伤 / 失去

| 维度 | 取 |
|---|---|
| 景别 | 中景（不靠近，也不走远）或背影远景 |
| 高度 | **略高**俯视，或平视但人不看镜头 |
| 朝向 | 侧面、背面 |
| 焦段 | 中长焦 |
| 构图 | 大量负空间；主体偏离中心 |
| 运动 | 固定。**悲伤不需要运镜。** |

- **反例**：悲伤配推轨变焦——那是崩溃，不是悲伤。
- **索引**：GrokFilm 062 负空间 / 009 平视

## 二、情绪转换：一场戏怎么从 A 走到 B

单个镜头只负责一个情绪；**一场戏靠"变化"打动人**。三种最稳的走法：

| 走法 | 镜头做法 | 例子 |
|---|---|---|
| **收紧** | 景别逐镜变近 + 机位逐镜降低 + 运动逐镜变慢 | 从远景的"他在人群里"，到近景的"他笑不出来了" |
| **松开** | 景别逐镜变远 + 机位升高 + 加负空间 | 从争吵近景，到最后一个大远景只剩一个人 |
| **破水平** | 前段全部平视水平，转折那一镜突然斜角/手持 | 全片越稳，破的那一下越狠——**所以别全片斜角** |

**关键**：转换必须发生在**同一场戏内**，观众才感觉得到"变了"。跨场戏的情绪变化，观众只会觉得是两场戏。

## 三、情绪错配的四个典型（学员最常犯）

| 症状 | 错在哪 | 改法 |
|---|---|---|
| 全场都紧张 | 一直用紧张处方，观众疲劳 | 紧张只占 20%，其余用"平静"垫，才有对比 |
| 情绪起不来 | 缺"转换"，每条镜头都是同一个情绪 | 加收紧或松开 |
| 观众不知道看谁 | 景别都对，但落点不明 | 用亮度/清晰度/对比把落点钉死（见 `05`） |
| 明明很惨却像广告 | 用了华丽运动（环绕、推轨变焦）拍苦难 | 苦难用固定＋中景，把运动留给希望 |

---

## 四、取用顺序（写每一镜时照做）

1. 这一镜**让观众感觉到什么**？（只许填一个情绪词）
2. 查表，取六项组合
3. 检查三项量：**距离 / 高度 / 停留时间**（运动越少＝停留越久）
4. 与前后镜比：情绪有没有变化？没变化就合并或重排
5. 写成提示词（`07`）
