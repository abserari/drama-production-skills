# 00-运镜机位总纲（导演调度操作层）

> **来源**：《导演运镜与机位构图》SKILL v1.3 的 SKILL.md 本体（2026-11-06 学习并入；
> 该 skill 是本目录 01-10 十篇手册的**源 skill**，手册已逐字节在库，此处只收其 SKILL.md 独有的操作流程）。
> **原文约束声明**：按 Seedance 2/2.5、可灵、9:16、≤30 秒约束改写——是**模型无关的镜头设计方法**。

## ⚠️ H3 适配口径（先读，压过原文）

1. **运镜列的落地换算**：下文所有"推/拉/移/环绕/推轨变焦"处方，在 H3 管线里只允许三种落地——
   **固定机位**（默认）、**纯摇**（同机位只改角度）、**两固定机位硬切**。位移式运镜实测 4 次全败，
   落笔前先过 `directing_bridge.md` §0 禁区。处方表的"运镜动态"列当**情绪方向指示**读
   （"推"= 收紧变近，那就用"下一拍更近的景别"或"缓缓下摇贴近"来实现），不当运镜指令读。
2. **交付格式冲突**：原文的"中文九段公式 / 200-300 字 / 一镜一句"是 Seedance 线口径。
   H3 管线交付一律走七段骨架 + 节拍制（`prompt_standard_v2.md`），本文件只取**机位决策层**。
3. **"相机固定在三脚架上"这类正向固定句式是好东西**：与 H3 兼容，直接可用；比否定句（"不推不拉"）
   服从度高——但注意 H3 连否定句也不必写，写"画框始终装得下 X"更稳。
4. **竖屏 9:16 专章**（05 手册）H3 管线暂用不上（出 1920×1080 横屏），保留备查。

## 一、一条总纲（其余全是推论）

> **情绪 = 观众与主体的距离 + 观众相对主体的高度 + 观众被允许看多久。**

机位不是风格选择，是情绪的物证。想让观众靠近就缩短距离；想疏远就拉远抬高；想不安就破坏水平。
所以永远从**情绪**进门，不从机位名词进门：先问"这一镜让人感觉到什么"，再问"相机在哪"。

## 二、主流程 A：剧本 → 镜头方案（六步）

1. **逼出一句话**：这场戏要观众带走什么？不是"两人吵架"，是"原来他一直知道"。写不出这句，后面全是白排。
2. **拆 beat**：beat ＝ 关系或信息发生变化的最小单位。30 秒的戏通常 2–3 个，超过 4 个说明想说的太多。**一个 beat 只给一个情绪词**。（H3 管线：beat 对应 directing_bridge 的"拍"，一段 3-4 拍。）
3. **查情绪处方**：按 `01-情绪与镜头的对应.md` 取六维组合。情绪必须**有变化**：整场按"收紧"（越来越近/越来越低/越来越慢）或"松开"（越来越远/越来越高/加负空间）排。全场同一情绪＝平。
4. **按 beat 配镜**：按 `02-剧情功能与镜头方案.md` 的八种 beat 配比取骨架。每个 beat 至少"给信息的一镜"＋"给反应的一镜"。
5. **填五决策 + 接点**：每镜五决策（见下）各只能有一个答案；序列补第六项接点（怎么交给下一镜：硬切/动作切/遮挡切/首尾帧桥/甩镜）。（H3 管线：接点＝段间硬切 + 裁头对齐，见 SKILL §6 收片。）
6. **落成段与提示词**：按 `directing_bridge.md` 换算成 H3 段，按 `prompt_standard_v2.md` 七段骨架写。

## 三、主流程 B：现成提示词 → 诊断 + 重写（四查）

**先判断属于哪种病，不要一上来就改词。按顺序查，第一个中的就是主因：**

| 查什么 | 症状 | 怎么改 |
|---|---|---|
| **1. 有没有回答"相机在哪"** | 只有主体和形容词，没有景别/角度/镜头 | 补五决策（`03`） |
| **2. 机位对不对情绪** | 有角度但用错（孤独给特写、压迫给大远景） | 按 `01` 换处方 |
| **3. 运动有没有三参数** | 写了"缓慢推进"没速度没终点；或叠了三个运动 | 补速度+终点；砍成单运动（`04`）——H3 里直接砍成固定/纯摇 |
| **4. 有没有自相矛盾/否定句** | "俯拍虫视""不要出现人""电影感" | 去矛盾、改正向、换成具体事实 |

**重写规则**：
- **只动机位与运动**，主体的动作与外观一个字别动（用户认的是那个主体）；
- 保留用户原意的画幅与风格词；
- 输出**改前 / 改后 / 三句话说明为什么**，说明里必须指出"原稿病在哪一条"。
- （H3 管线附加：改完后必须过 `check_prompt_v2.py` preflight，情绪词/呼吸词等房规项一并清零。）

## 四、五决策（每镜必答，留空＝交给模型瞎猜）

1. **距离**：大远景 / 远景 / 中景 / 中近景 / 近景 / 大特写
2. **高度与水平**：地面 / 平视 / 高位 / 俯拍正扣 / 鸟瞰 / 航拍 / 虫视；地平线是否倾斜
3. **朝向**：正面 / 侧面 / 四分之三 / 背面 / 过肩 / 第一人称 / 自拍
4. **镜头与焦点**：广角畸变 / 标准 / 长焦压缩 / 微距；浅景深或深焦；前景遮挡
5. **运动**：固定 / 推 / 拉 / 摇 / 移 / 跟 / 升 / 手持 / 环绕 / 变焦 / 推轨变焦——**种类 + 速度 + 终点**（H3：只许固定/纯摇/硬切）
6. **接点**（序列才有）：硬切 / 动作切 / 遮挡切 / 首尾帧桥 / 甩镜

同一条只能有一个答案。"俯拍虫视""微距大远景"会让模型随机挑一个。

## 五、写提示词的机位三件事

1. **镜头句放最前面**（画幅→景别→机位→镜头），主体细节在后——前面的话权重最高；
2. **说清这个角度要达成什么，并给一个只有它才有的视觉证据**。例："让人显得被困" → "天花板的横梁压在画面上三分之一"；
3. **一镜一个运动，有速度有终点**。要静止就明写"相机固定"。（H3：写到 [节拍 N] 的"镜头："字段，机位锚在实物上——"机位贴在吧台台面上"比"低角度"稳。）

## 六、机位层自检清单（每版过一遍）

- [ ] 这场戏的"一句话"写得出吗？
- [ ] 每个 beat 有情绪词，且整场情绪**有变化**？
- [ ] 每一镜的机位能对上 `01` 的处方，不是随手选的？
- [ ] 五决策各只有一个答案，没有互相矛盾？
- [ ] 主体与机位的关系说得清"为什么"，不是"我觉得好看"？
- [ ] 相邻两镜换了景别或角度？180° 线守住了？
- [ ] 运动：一个、有速度、有终点？（H3：是否已换算成固定/纯摇/硬切？）
- [ ] 提示词：镜头句在最前、无否定句、无"电影感"这类空词？

## 七、三条最容易踩的错

1. **孤独给特写**——一靠近就不孤独了；
2. **悲伤配推轨变焦**——那是崩溃，不是悲伤（悲伤用固定机位 + 负空间，恰好与 H3 兼容）；
3. **全片都紧张 / 全片都斜角**——没有对比，情绪就不成立。
