# 参考图（资产）生成规范

> 参考图的质量上限就是成片的上限——H3 画人靠 `@图片N` 锚定，图里没有的特征
> 靠文字补是补不稳的（服装反描写、占画比例反噬都是实测教训）。本文规定
> **生成参考图时的内容与格式要求**，产出后放
> `D:/Comfy-Desktop/ComfyUI-Shared/input/cglide/<项目>/`，**文件名即别名**
> （提交时 `--assets 素材.json` 按文件名映射到图槽）。
>
> **生成工具**：用户指定用 ComfyUI「生图qwen-image_2.1全能编辑-1015」工作流生成
> （2026-11-01 拍板），API 驱动方法与坑见 `references/qwen_image_gen.md`，
> 一键脚本 `scripts/qwen_asset_gen.py`（单张/批量，自动拷入 cglide）。

## 1. 通用格式要求

| 项 | 要求 | 原因 |
|---|---|---|
| 比例 | **横图 16:9**（1216×704 或同比例） | 与成片同比例；竖图/方图会被 H3 裁切或撑出黑边。**但仅约束"新生成"的参考图——用户自备/已有的参考图不切割、不改比例（2026-11-02 用户拍板），asset_check 的比例 FAIL 只提示、不作为重生成理由，用户确认即用** |
| 分辨率 | ≥1024 长边 | 低于一采分辨率会被上采样糊化，特征变模糊 |
| 单段图槽 | **每段 1-3 张** | H3 共 9 图槽，多图增加漂移概率（实测） |
| 项目资产池 | 建议 **≤6 张**：主角 1 + 对手 1 + 主场景 1-2 + 关键道具 0-1 | 图槽复用同一张，跨段一致性反而更好 |

## 2. 人物参考图

### 标准生成模板：五视图角色设定图（2026-11-01 用户拍板，直接喂生图工具）

> 人物资产图一律按此模板生成，产出横版设定图放 `cglide/<项目>/<角色名>.png`。
> 五视图（头部正/侧 + 服饰正/左/背）一次锁定面部特征与整套服装，H3 引用单图即可
> 提取全部特征——比多张散图跨段一致性更好，也天然满足"多人分图"。
> 模板中「以图2为准」指服装基准图（双图工作流时图2=服装设定图）；
> **单图工作流把这句改成「以本图为准」**。
> 配合提示词侧规则：Subject 行的 `权限=` 仍要写「不复制原图机位，不复制占画比例」
> （设定图是平视棚拍拼版，正文景别/机位依旧由节拍文本驱动）。

```
提取并保持人物的面部特征、脸型、五官比例、发型、肤色、年龄气质与身份一致性；提取并保持整套服装的款式结构、层次搭配、颜色组合、面料材质、纹理细节、裤装/鞋履关系与整体穿搭风格。

横向构图，纯净纯白色无缝背景，中性摄影棚灯光，柔和前侧平光，布光均匀，轮廓清晰，肤色自然，服装结构与材质纹理准确。
严格布局规范：画面水平左侧约三分之一区域纵向排列两张头部视图，上方为角色正面头部特写，下方为同一角色侧脸头部特写；左侧两张视图之间保持干净留白。画面右侧剩余约三分之二水平区域横向并列摆放三张视图，顺序为：正面服饰视图、左侧面服饰视图、背面服饰视图。右侧三张视图直接截除头部，画面从颈部以下开始展示身体服饰，不呈现头部。五个视图之间使用2px宽、#E2E2E2淡灰色的竖向或细分隔线，线条平直统一。

平视镜头，右侧三张服饰视图完整展示人物躯干至鞋底，无画面裁剪。人物自然直立站姿，双臂自然下垂，双手放松空手，无任何握持物品。左侧上方正面头部特写五官清晰；左侧下方侧脸头部特写展示同一人物侧脸轮廓、发型、耳部、下颌线与面部结构。

五张视图中，人物面部特征、发型、体型、肤色与身份比例保持统一；服装款式、结构层次、颜色搭配、材质纹理、褶皱细节与伤痕污渍位置以图2为准，并在五个视图中保持一致。禁止任何道具、武器、食物、饮品、手持物品；禁止大幅度动作、夸张表情、强烈情绪、面部遮挡。无环境场景，仅纯白背景，不存在其他人物。无文字、水印、标签、标注、尺寸标识、Logo、UI界面元素。
```

模板与本节其余条款的关系：五视图全身立姿属于**设定图特例**，§2-1 的
「占画 1/3~1/2」约束不适用于设定图内部的各视图；禁止道具/手持物与 §4 道具
规范互补——**道具单独出图，不进角色设定图**。

1. **构图留白**：人物占画面 **1/3 ~ 1/2**，四周留环境——**不要顶满画面的特写**（单视图照/立绘类参考；五视图设定图见上方模板）。
   实测：主体占满画面的参考照会让 H3 按参考图占画比例画，文字里写的
   「大远景、人物只占画面 1/6」全部失效（所以 Subject 的 `权限=` 才被迫加
   「不复制占画比例」这句防反噬；图本身留白才是根治）。
2. **机位中性**：平视、正面或 3/4 侧，**不要极端仰拍/俯拍/广角畸变**——机位同样会被复制。
3. **特征可描述**：图里的人物要能支撑一句内联定义（发型/发色/上衣/标志物 +
   否定项），如「黑色齐耳短发波波头、米色打补丁短衫，不是红裙不是双马尾」。
   **正文反衣物描写**（衣物只写随动），所以特征必须一次定死在图+定义里。
4. **表情中性、姿态自然站立**：表情和动作由节拍文本驱动，参考图带强烈表情
   （狞笑/大哭）会污染所有段的面部。
5. **多人分图**：每张图一个人。双人同框图慎用——两个身份互相锚定，段里只出
   一人时容易串特征。

## 3. 场景参考图（2026-11-01 拍板：主锚 + 反向角双图）

**每场戏 1-2 张**：先生成主锚图，机位会转出主锚覆盖范围（看到另一面墙/另一侧
街道）时再派生一张反向角图。社区实测（seedance H3 环境一致性专文）：H3 转出
未见区域时会自己"发明"那面墙——**给一张兼容的反向角参考，而不是让模型编**。
两张图必须同场地：反向角用**图生图 / 同 seed** 从主锚派生，不要独立生成
（独立生成的"同场景"必然是两个场景）。

### 3.1 主锚图生成模板（直接喂生图工具，可按场地增删物件）

```
提取并保持此空间的几何结构、地面与墙面材质、门窗位置与开启方向、固定家具与陈设的位置关系、主光源方向与色温、环境材质细节（木纹/砖缝/金属氧化/水渍痕迹），全部在整图中保持一致。

横向构图 16:9，大全景视野，画面完整容纳人物将活动的全部区域，纵深层次清晰（前景/中景/背景可辨）。完全无人物、无动物。中性自然光，主光方向明确单一，阴影柔和统一，色彩自然不过饱和。

禁止：任何人物或动物身影、文字、水印、标签、Logo、UI界面元素、画面裁切、夸张广角畸变。
```

> 主光方向就是后续各段 `时间光线` 行要写的方向（都写「主光从右侧铺入」这种），
> 生成时就要定死，别生成完再看图猜。

### 3.2 反向角派生规范

- **派生方法**：主锚图作图1，图生图（低重绘幅度保结构），或同 seed + 机位指令
  （「同一空间，从对面墙看回去，保持全部门窗家具位置与光源方向不变」）
- **何时需要**：分镜里出现「转过身看向门口」「从室内拍到窗外」这类
  视线/机位反转的段，且反转后能看到主锚图里看不见的区域
- **引用方式**：该段 `素材.json` 同时挂主锚 + 反向角（图槽够用时）；
  图槽紧张时只给当段机位对应的那张
- **自检**：两张图的门窗位置、家具、光源方向必须互洽（门在主锚里靠左，
  反向角里就该靠右）——派生后并排检查一遍再用

### 3.3 配套文字规范：「环境锁块」（无论几张图都要写）

Subject 场景行的 `锁定空间` 权限之外，正文的空间环境行按**清单式**写，
不写情绪形容词（「氛围感拉满的破败」对 H3 是零信息）：

```
空间环境：<Subject 2>；
几何锚点：门位于左侧墙，窗在门的正上方，工作台沿右侧墙摆放；
材质：铸铁墙面、木地板（缝线可见）、黄铜闸刀；
光：主光从右侧高窗斜入，冷色 5600K，台面有第二光源（油灯）暖色补光。
```

要点（来自 H3 社区实测）：**关系式描述强于罗列**（「窗在门的正上方」比
「窗、门、工作台」稳得多）；只点名必须 persist 的物件并给位置/颜色/材质；
杂乱小物件直接删——物件越少，跨段越稳。

## 4. 道具参考图（2026-11-01 拍板：三视图 + 双特写拼版）

### 标准生成模板（与角色五视图拼版同构，直接喂生图工具）

> 主要道具一律按此模板生成，产出横版拼图放 `cglide/<项目>/<道具名>.png`。
> 布局对齐角色模板笔法：左侧三视图锁轮廓，右侧双特写锁材质与机构——
> 特写格直接服务拟音的材质词（黄铜/皮革/玻璃在特写里必须可辨）。

```
提取并保持此道具的整体轮廓与剪影比例、结构构造与部件组成、材质与表面处理（金属拉丝/皮革纹理/漆面磨损）、颜色组合、接缝与铰链位置、磨损与使用痕迹的位置和程度，全部在整图中保持一致。

横向构图，纯净浅灰色无缝影棚背景，中性摄影棚灯光，柔光主灯加轻微轮廓光，底部自然接触阴影，材质高光真实，无夸张反射。
严格布局规范：画面左侧约百分之六十区域横向并列三张视图，顺序为正面视图、90度侧面视图、背面视图，三张视图为同一道具、比例严格一致；画面右侧约百分之四十区域纵向排列两个特写研究视图，上方为主机构或主面部的放大特写，下方为次级细节（铰链/握柄/铭刻/内部结构）放大特写。各视图之间保持干净留白，布局平直统一。

平视镜头，三张整视图完整展示道具全貌，无画面裁剪。特写视图边缘清晰，材质纹理与做工细节可辨。

各视图中的道具必须是同一件：比例、颜色、材质、部件位置、磨损伤痕位置完全一致。禁止：文字、标签、水印、Logo、尺寸标注、人物、手部、背景环境、额外装饰物、画面外元素。
```

### 4.1 使用状态格（可选扩展）

道具在剧中有状态变化的（怀表开/合、灯具亮/灭、闸刀抬起/落下），在模板
「严格布局规范」末尾追加一句：

```
右侧下方特写旁增加一格该道具的使用状态视图（如怀表开盖、灯具点亮），
其余视图保持收纳或关闭状态。
```

### 4.2 尺度用文字锁（拼版图不放参照物）

拼版棚拍没有环境，**尺度靠 subject_definitions 文字定义**，不往图里塞
人形/硬币等参照物（会引入污染：手部崩坏、参照物被 H3 当成画面元素画进成片）：

```
- <Subject 3> 为 @图片3 中的黄铜怀表，尺度锚点=约半臂长直径、单手可握、
  可开盖；权限=锁定轮廓与识别特征（表冠在12点位、链环扣在6点位），
  不复制参考图的机位，不复制它的占画比例。
```

### 4.3 车辆类特殊要求

**驾驶位方向盘可见**（左舵/右舵一眼可确认）——实测教训：用车外人物站位
反推舵向，白跑一条 175 帧。车辆走本节拼版模板时，三视图中的侧面视图必须
含驾驶舱侧窗内的方向盘轮廓。

### 4.4 与正文/拟音的配合

- **磨损伤痕位置一次定死**（与角色服装同规则）：拼图里定好的划痕位置，
  正文节拍不重复描述，只在「衣物随动」级别的随动描述里提
- **拟音点名材质**：每拍 `音效：` 的材质词（黄铜轻响/皮革摩擦）必须能在
  特写格里找到对应材质——图里看不清材质的道具，重生成而不是硬写

## 5. FL2VA 首尾帧锚图（精简版工作流的图片1/图片2）

- **起点帧锚（图片1）**：续接段直接用**上一段段尾帧**，不用单独生成——
  这正是续接的意义（段首状态被钉帧锁死）。
- **终点帧锚（图片2）**：要与目标构图一致（居中/背对机位/与钟面同框这类
  状态写进 Subject 权限行），生成或挑选时按**最终想要的那一帧**来定，
  不是按"场景大概长这样"来定。
- 首尾帧锚图同样遵守 §1 比例要求；正文写「两帧之间的可观察路径」，
  不分别描述两张图（详见 `prompt_standard_v2.md` FL2VA 节）。

## 6. 自检清单（生成完对照一遍）

几何项先用 `asset_check.py` 自动初筛（比例/分辨率/背景均匀度），
内容项人工过：

- [ ] 横图（16:9 或 1216:704）、长边 ≥1024——asset_check 自动查
- [ ] 人物图：主体占画 1/3~1/2、机位中性、表情中性、能写出一句内联特征定义
- [ ] 场景主锚图：无人、光源方向明确、装得下人物活动范围（§3.1 模板生成）
- [ ] 需要反向角的场次：反向角由主锚图生图/同 seed 派生，门窗家具光源互洽（§3.2）
- [ ] 正文空间环境行按「环境锁块」清单式写，关系式描述、无情绪形容词（§3.3）
- [ ] 道具图：按 §4 拼版模板生成，特写材质可辨；尺度已写进 subject_definitions（图内无参照物）；车辆图方向盘可见
- [ ] 有使用状态的道具：状态格已加（§4.1）；正文与拟音材质词能对上特写格（§4.4）
- [ ] 文件名 = 别名（中文可直接用），已放 `cglide/<项目>/`
- [ ] 项目资产池 ≤6 张，每段用量 1-3 张
