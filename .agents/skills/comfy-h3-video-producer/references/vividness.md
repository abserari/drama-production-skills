# 画面生动 + 逻辑通顺：可执行清单

> 这份文档解决两种"能用但难看"的片子：
> **A. 画面不动**（站着说话、背景是壁纸、环境不参与演出）→ 第一、二、三节
> **B. 逻辑不通**（人为什么动、动作接不上、观众看不懂这段在讲什么）→ 第四节
>
> 用法：写完一段提示词，拿第五节的清单逐拍勾；勾不满就先改，不要拿去烧生成。

---

## 一、铁律：每一拍都要有"动作动机"

一拍里如果只能回答"他做了什么"，不能回答"**他为什么要做**"，这一拍就是摆拍。

| 摆拍（无动机） | 有动机 |
|---|---|
| 她站在门口看着沙海 | 她抬手挡了一下扑到脸上的风，才把视线投向沙海 |
| 男人坐在桌边 | 他把杯子往桌心推了两寸，腾出手来指地图上的一个点 |
| 两人对视 | 他先移开视线去够桌上的钥匙，她才抬眼看他 |

写法：**动机不必写进提示词**（H3 不需要心理描写），但你要用它来决定
"这一拍的第一动作是什么、身体朝向谁、手在干什么"。动机决定构图，构图骗不了人。

---

## 二、生动三件套：每拍至少各一项

### 1. 动作因果链（主动件 → 传导 → 落点）

不要写"他转身"。写"他右脚先转 30°、重心跟着挪、肩线最后才转过来、衣摆甩出一个延迟"。
传导顺序错了，模型会给出"整体旋转"的塑料感。

```
他的右手先离桌沿（主动），肘部跟着外旋（传导），指尖扫过桌面把一张纸带起半寸（落点）。
```

### 2. 环境反馈（动作改变了环境）

**环境必须是"被角色推动的"，不是背景板。** 每拍至少一项"角色一动，环境跟着变"：

- 走过 → 地面积尘被带起一缕，在他脚后 20cm 处散开
- 放下灯 → 桌面光斑从圆形压扁成椭圆，墙上影子跟着矮下去
- 推门 → 门缝里的光带在墙上扫过 15°，浮尘在光带里翻涌
- 坐下 → 布垫被压出褶，边缘回弹两次

### 3. 材质触感（可见的"重量"）

H3 对"接触面"的描写非常敏感，写了就有物理感：

- 手指按下 → 指腹压出白痕，抬起后回血 0.3 秒
- 鞋底落沙 → 脚陷 1cm，沙从鞋边挤出
- 握住木杆 → 掌心与木面之间没有缝，前臂肌肉轻绷
- 布料摩擦 → 肩部接缝被拉起一个小三角褶

> 这三件套对应的就是 `prompt_standard_v2.md` 三-②（动力学链）/三-③（环境次级运动）/⑤（四层画面）。
> 这里只补一件事：**要让它"因为角色"而变**，而不是各写各的。

---

## 三、机位库：让"信息"代替"运动"

画面闷，往往不是运动不够，是**信息不够**。换机位比加运镜便宜：

| 机位 | 解决什么 | 写法示例（填进 `镜头：`） |
|---|---|---|
| 前景遮挡 | 空间有纵深、不空 | 前景一根立柱占画面左侧三分之一，焦点在他脸上，柱子轻微失焦 |
| 手部插入 | 给出"正在做事" | 机位略低于手，只有双手与桌面入画，人物面部不入画 |
| 越肩 | 关系与视线方向 | 机位在他右肩后 40cm，越过肩线看她，肩线占画面右下角 |
| 门框/窗框框住 | 建立"边界"与被困感 | 门框把画面切成 2:1，她站在窄的一侧 |
| 反打 | 对话的压迫感 | 硬切至她的正面，机位齐她眼高，背景是他的肩线（虚） |
| 物件特写 | 把情绪落到实物上 | 只有那枚珠子与两根手指入画，指腹压出白痕 |
| 跟拍 | 速度与不安 | 机位随她平移，保持她始终在画面左三分之一，背景连续后掠 |
| 拉远揭示 | 收尾、给"更大的世界" | 升至八米、俯角 25°，人物缩到画面下三分之一，沙海占满上部 |

**一镜一个动作单元**。同一拍里塞两个动作，H3 会把两个都做一半。

## 四、逻辑四问（写完一段必答，答不出就重排）

### 问 1：他这一刻想要什么？

答案必须是**具体动作**（拿到珠子 / 不让她进门 / 看清门外是谁），不能是"表达悲伤"。
答不出来 → 这一拍没有存在必要，删掉或合并。

### 问 2：他在哪、朝向谁、手在哪？

跨段最容易断的就是这三项。每一段结尾必须有 `[结尾状态]` 写死：
位置、朝向、视线落点、手部状态、道具状态。下一段的 `[节拍 1]` 从这个状态起手。

### 问 3：时间与光线连续吗？

同一场戏，主光方向、色温、影长必须一致。上一段是"低角度暖金从右铺入"，
下一段突然"冷蓝顶光"，观众会立刻觉得换了一天 —— 除非你**故意**用光线变化表示时间流逝，
那就要在段首写明（"光线已从侧暖转为顶冷，约过了两小时"）。

### 问 4：因果链断了吗？

逐拍问"因为上一拍发生了什么，所以这一拍才这样"。断了通常是两种错：

| 断裂类型 | 症状 | 修法 |
|---|---|---|
| 动作跳步 | 上一拍手还垂着，这一拍珠子已经在掌心 | 补一拍"伸手 + 拿起"，或在本拍写清"从腰侧抬起、到胸前摊开" |
| 反应错位 | 对方说完话，他立刻笑了，中间没有"听见"的过程 | 加 0.5s 的"听见"：眼睑抬一下、呼吸停一拍，再给反应 |

## 五、逐拍自检（勾不满别提交）

- [ ] 这一拍有明确动机，且动机体现在**第一个动作**上
- [ ] 动作有因果链：主动件 → 稳定件 → 补偿件 → 不自主反应
- [ ] 至少一项**由角色引起**的环境反馈
- [ ] 至少一项材质触感 / 接触面反应
- [ ] 四层画面齐全（前景 / 角色层 / 背景 / **空气层**）—— 空画面 99% 是漏了空气层
- [ ] 机位给出的是"新信息"，不是"换个角度再看一遍同一件事"
- [ ] 和上一拍的衔接词明确：`接上一镜，机位不变` 或 `硬切至…`
- [ ] 这一拍的声音是"动作直接产生的"（拟音），不是环境垫音
- [ ] 没有情绪形容词，全部换成可见的肌肉动作
- [ ] 全段只服务一个主要事件，没有跨空间/跨时空

## 六、12 条死画面与改法

| 死画面 | 为什么死 | 改法 |
|---|---|---|
| 人物站着说话，背景静止 | 环境不参与演出 | 加"风吹动他衣角、背后布帘鼓一下" |
| 全程中景 | 没有情绪距离变化 | 至少一次切到特写，或一次拉远揭示 |
| 动作只写一个部位 | 恐怖片式僵直 | 补稳定件与补偿件 |
| 表情靠形容词 | 模型自由发挥 | 换成 2-3 个可见肌肉动作 |
| 每拍都"固定机位" | 节奏平 | 重锤那拍给运动，其余固定 |
| 环境次级运动没方向没频率 | 等于没写 | "从画面左侧吹入，每秒 2 次，幅度 1-2cm" |
| 光只写"昏暗" | 没有表面交互 | 写主光方向 + 落点 + 第二光源 + 反射 + 阴影 |
| 说话时手不动 | 人不会这样说话 | 给手一个与台词同步的小动作 |
| 五镜平均 2 秒 | 切点机械 | 切点踩动作（脚停/手摊/抬头/嘴角回位） |
| 每段都从"全景"开始 | 像幻灯片 | 直接进中景或特写，全景留给揭示 |
| 收尾没有落点 | 观众不知道看哪 | `[结尾状态]` 写死视线与构图重心 |
| 声音只有台词 | 画面质感少一半 | 每拍点名拟音（脚步/布料/器物） |

## 七、改写示例（同一事件的两种写法）

**死画面版**（信息为零，动作无因果）：

```
[节拍 1] 镜头：中景，固定。画面：她走到门口，看着外面。神态：平静。环境：风。
音效：风声。仅此一类，无其他声音。
```

**生动版**（动机明确、环境被推动、材质可见）：

```
[节拍 1] 镜头：机位齐她肩高，门框把画面切成 2:1，她站在窄的一侧，固定。
画面：她右手先抬到门框上（指腹压住木面，压出一道浅白痕），重心前移到左脚，
      肩线跟着转 15°，衣摆晚半拍才甩过来；视线越过门缝投到外面。
神态：眼睑眯到只留一条缝，眉头向中间收 2mm，嘴唇闭合，鼻翼随吸气张开一次。
环境：门缝漏进的光带在她手背上扫过 15°，浮尘在光带里翻涌；门外风把她的发梢
      从画面左侧吹向右侧，每秒 2 次，幅度 1-2cm。
音效：掌心压上木门框的一声闷响（约 0.2 秒）；衣料摩擦；门外风掠过门缝的短促气声。
      仅此三类，无其他声音。
```

差别不在文采，在于：**观众能看出她要干什么、门有多重、风从哪来**。
