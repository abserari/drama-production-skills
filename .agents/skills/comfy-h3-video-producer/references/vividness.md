# 画面生动 + 逻辑通顺：可执行清单

> 这份文档解决两种"能用但难看"的片子：
> **A. 画面不动**（站着说话、背景是壁纸、环境不参与演出）→ 第一、二、三节
> **B. 逻辑不通**（人为什么动、动作接不上、观众看不懂这段在讲什么）→ 第四节
>
> 用法：写完一段提示词，拿第五节的清单逐拍勾；勾不满就先改，不要拿去烧生成。

---

## 一、铁律：每一拍都要有"动作动机"

一拍里如果只能回答"他做了什么"，不能回答"**他为什么要做**"，这一拍就是摆拍。

| 摆拍（无动机） | 有动机 |
|---|---|
| 她站在门口看着沙海 | 她抬手挡了一下扑到脸上的风，才把视线投向沙海 |
| 男人坐在桌边 | 他把杯子往桌心推了两寸，腾出手来指地图上的一个点 |
| 两人对视 | 他先移开视线去够桌上的钥匙，她才抬眼看他 |

写法：**动机不必写进提示词**（H3 不需要心理描写），但你要用它来决定
"这一拍的第一动作是什么、身体朝向谁、手在干什么"。动机决定构图，构图骗不了人。

---

## 二、生动三件套：每拍至少各一项

### 1. 动作因果链（主动件 → 传导 → 落点）

不要写"他转身"。写"他右脚先转 30°、重心跟着挪、肩线最后才转过来、衣摆甩出一个延迟"。
传导顺序错了，模型会给出"整体旋转"的塑料感。

```
他的右手先离桌沿（主动），肘部跟着外旋（传导），指尖扫过桌面把一张纸带起半寸（落点）。
```

### 2. 环境反馈（动作改变了环境）

**环境必须是"被角色推动的"，不是背景板。** 每拍至少一项"角色一动，环境跟着变"：

- 走过 → 地面积尘被带起一缕，在他脚后 20cm 处散开
- 放下灯 → 桌面光斑从圆形压扁成椭圆，墙上影子跟着矮下去
- 推门 → 门缝里的光带在墙上扫过 15°，浮尘在光带里翻涌
- 坐下 → 布垫被压出褶，边缘回弹两次

### 3. 材质触感（可见的"重量"）

H3 对"接触面"的描写非常敏感，写了就有物理感：

- 手指按下 → 指腹压出白痕，抬起后回血 0.3 秒
- 鞋底落沙 → 脚陷 1cm，沙从鞋边挤出
- 握住木杆 → 掌心与木面之间没有缝，前臂肌肉轻绷
- 布料摩擦 → 肩部接缝被拉起一个小三角褶

### 4. 空间矢量与视线脱钩（机位视锥 vs 交互目标）（v2.3 扩充）

**生动不是乱动，是几何关系绝对可信。** 孤立写「背对镜头」必崩（模型常把角色转到背对交互目标）：
- **机体正向**：正面躯干永远朝向正在操作的物件（售货机/控制台/对手），角度精确到几何度数；
- **机位视锥**：后背或侧脸迎向镜头平移方向，指明夹角（例如呈 45° 侧背入画）；
- **视线锁死**：视线 100% 投向目标物操作点，严禁直视镜头，彻底根除出戏的死鱼眼窥视。

### 5. 物理动量惯性与跨台词双轨多任务（Dual-Track Performance）（v2.5 扩充）

**说话不是运动的刹车片，动量绝不因发声而中断。**
AI 视频常见“一说话角色就立刻立正僵死（Talking Freeze Syndrome）”，根因是交叉注意力聚焦口型导致四肢动作指令归零。
- **动量强捆绑**：每一句 `<d>` 台词后，显式声明下半身或肢体作业的物理惯性延续（如迈步交替未停、重心起伏向前、手头旋拧作业持续）；
- **双轨演出**：将台词（听觉轨）与物理动量（视觉轨）并行推进（边走边说 Walk-and-Talk、边干边说 Busy Hands、边探边说 Scanning-while-Moving）；
- **动量保护约束**：显式加入否定禁令「严禁发声时身躯骤停立正，物理动量全程线性延续」。

> 这五件套对应的就是 `prompt_standard_v2.md` 三-②（动力学链）/三-③（环境次级运动）/⑤（四层画面）/⑦-⑩（空间矢量与微表情）/⑯（物理惯性与双轨多任务）。
> 核心：**让角色在三维空间中扎实存在，与环境和道具建立真实的物理相互作用，动作动量自然连贯。**

## 三、电影级高阶机位与镜头语言库（v2.4 深度扩充）

画面闷、像纸片人，往往不是运动不够，是**镜头语言与信息层级不够**。根据叙事功能主动调用以下电影技法：

| 机位语言 | 叙事目的与心理效果 | 工业级写法示例（填入 `镜头：` 行） |
|---|---|---|
| **正反打越肩（OTS）** | 双人对话、关系对峙、视线咬合 | `过肩近景（OTS, 85mm, f/1.8），机位在<Subject 1>右肩后35cm；右肩与后发轮廓严重虚化占据右下角1/5；焦点清晰锁定中景正前方的<Subject 2>面部，两人视线严格沿180度轴线对齐。` |
| **前景虚焦遮挡（Dirty Frame）** | 打破平面感、现场呼吸感、窥视沉浸 | `机位齐腰，前景左侧横贯一根生锈的斑驳钢管（极大虚焦，占左侧1/3形成天然框景）；焦点穿过钢管空隙锁定中景正在检修的机器人，背景废墟建筑呈柔和圆形散景。` |
| **焦点平滑转移（Rack Focus）** | 引导注意力流动、因果揭示、情感转折 | `固定机位（85mm浅景深）；第1.5秒焦点通过 Rack Focus 在0.6秒内由前景指尖颤抖的硬币平滑拉到后景他紧抿的唇角与眼眸，硬币随之融化为边缘柔和的光斑。` |
| **框中框自然裁切（Framing in Depth）** | 压抑感、孤独被困、空间秩序 | `中景（35mm），废弃车门与车窗框把画幅切成 2:1 的狭长框景，角色伫立在窄光一侧，深暗车体将人物压在视觉中心。` |
| **超低贴地仰拍（Worm's Eye View）** | 机械体压迫感、行走冲击、地貌细节 | `超低机位距地表8cm贴地微仰拍（24mm大广角, f/8深焦）；前景履带碾过碎石伴随泥浆外挤，后景机器人庞大机躯沿仰视透视直插昏暗天际。` |
| **微俯角（High-Angle 20°）** | 脆弱、孤独、被环境吞噬 | `微俯拍20度（50mm），机位高两米；人物蜷缩在破旧候车亭长椅的一角，湿漉漉的地面反光与巨大的空荡站台形成压制。` |
| **局部特写插入（Cut-in Insert）** | 聚焦高密度物理信息、微动作重锤 | `特写（100mm微距），只有机械抓手的指节与铜质旋钮入画，金属受力接缝下压1mm，背景彻底虚化为纯黑。` |

**镜头语言铁律**：
1. **一镜一个主焦点**：如果要转移焦点，写清起点、时长与落点（Rack Focus）；
2. **前景遮挡要失焦**：前景杂物写「严重失焦/虚化」，否则模型会分不清谁是中景主角；
3. **对话严格守轴**：双人正反打必须声明在同侧（180度轴线），避免角色视线方向反冲。

## 四、逻辑四问（写完一段必答，答不出就重排）

### 问 1：他这一刻想要什么？

答案必须是**具体动作**（拿到珠子 / 不让她进门 / 看清门外是谁），不能是"表达悲伤"。
答不出来 → 这一拍没有存在必要，删掉或合并。

### 问 2：他在哪、朝向谁、手在哪？（五维空间矢量）

跨段与镜头内最容易断的就是这三项。
- **在哪**：空间绝对坐标（如街道东侧人行道、售货机正面 30cm）；
- **朝向谁**：机体正面朝向什么方位、与交互物体的夹角（解耦摄影机位置，严禁只写"背对镜头"）；
- **视线在哪**：视线钉死在具体哪一点，显式声明与镜头无眼神交互；
- **手与重心在哪**：接触面（脚底板轴心、掌心受力点）与姿态锁定。
每一段结尾必须有 `[结尾状态]` 写成不可逆的死条款，下一段的 `[节拍 1]` 从这个状态起手。

### 问 3：时间与光线连续吗？

同一场戏，主光方向、色温、影长必须一致。上一段是"低角度暖金从右铺入"，
下一段突然"冷蓝顶光"，观众会立刻觉得换了一天 —— 除非你**故意**用光线变化表示时间流逝，
那就要在段首写明（"光线已从侧暖转为顶冷，约过了两小时"）。

### 问 4：因果链断了吗？

逐拍问"因为上一拍发生了什么，所以这一拍才这样"。断了通常是两种错：

| 断裂类型 | 症状 | 修法 |
|---|---|---|
| 动作跳步 | 上一拍手还垂着，这一拍珠子已经在掌心 | 补一拍"伸手 + 拿起"，或在本拍写清"从腰侧抬起、到胸前摊开" |
| 反应错位 | 对方说完话，他立刻笑了，中间没有"听见"的过程 | 加 0.5s 的"听见"：眼睑抬一下、呼吸停一拍，再给反应 |

## 五、逐拍自检（勾不满别提交）

- [ ] 这一拍有明确动机，且动机体现在**第一个动作**上
- [ ] 动作有因果链：主动件 → 稳定件 → 补偿件 → 不自主反应
- [ ] **空间朝向三维解耦**：机体绝对朝向 + 交互目标 + 视锥夹角写全，无孤立模糊的"面对/背对镜头"
- [ ] **视线彻底锁定**：眼球或主光学传感器绝对钉死在操作目标，无直视机位（Anti-Lens Gaze Locking）
- [ ] **电影级镜头语言**：对话段使用正反打越肩（OTS）、站位主动设计虚焦前景遮挡（Dirty Frame）、关键转折使用焦点转移（Rack Focus）
- [ ] **光学参数物理化**：标注等效焦段（24/35/50/85mm）与景深（浅景深 f/1.8 + 散景 或 深焦 f/8）
- [ ] **动作两端动力学**：大动作包含动势预备（反向蓄力）与刹停惯性回弹（Overshoot）
- [ ] **物理惯性与双轨多任务**：台词节拍捆绑下半身动量或作业动作（边走边说/边干边说），显式声明禁止发声时骤停立正（Anti-Freeze on Talk）
- [ ] **台词发音微动态**：发声前0.15s唇齿预备，发声完毕干净收束，无假唱吞字
- [ ] **转向带有轴心度数**：减速刹停 → 接触面轴心顺/逆时针转向 N 度 → 终态几何锁定
- [ ] **非人/机械体有微表情**：光学光圈微变焦、LED呼吸频闪、姿态三轴角（Yaw/Pitch/Roll）微动
- [ ] 至少一项**由角色引起**的环境反馈
- [ ] 至少一项材质触感 / 接触面反应
- [ ] 四层画面齐全（前景 / 角色层 / 背景 / **空气层**）—— 空画面 99% 是漏了空气层
- [ ] 机位给出的是"新信息"，不是"换个角度再看一遍同一件事"
- [ ] 和上一拍的衔接词明确：`接上一镜，机位不变` 或 `硬切至…`
- [ ] 这一拍的声音是"动作直接产生的"（拟音），不是环境垫音
- [ ] 没有情绪形容词，全部换成可见的肌肉动作
- [ ] 全段只服务一个主要事件，没有跨空间/跨时空

## 六、12 条死画面与改法

| 死画面 | 为什么死 | 改法 |
|---|---|---|
| 人物站着说话，背景静止 | 环境不参与演出 | 加"风吹动他衣角、背后布帘鼓一下" |
| 全程中景 | 没有情绪距离变化 | 至少一次切到特写，或一次拉远揭示 |
| 动作只写一个部位 | 恐怖片式僵直 | 补稳定件与补偿件 |
| 表情靠形容词 | 模型自由发挥 | 换成 2-3 个可见肌肉动作 |
| 每拍都"固定机位" | 节奏平 | 重锤那拍给运动，其余固定 |
| 环境次级运动没方向没频率 | 等于没写 | "从画面左侧吹入，每秒 2 次，幅度 1-2cm" |
| 光只写"昏暗" | 没有表面交互 | 写主光方向 + 落点 + 第二光源 + 反射 + 阴影 |
| 说话时手不动 | 人不会这样说话 | 给手一个与台词同步的小动作 |
| 五镜平均 2 秒 | 切点机械 | 切点踩动作（脚停/手摊/抬头/嘴角回位） |
| 每段都从"全景"开始 | 像幻灯片 | 直接进中景或特写，全景留给揭示 |
| 收尾没有落点 | 观众不知道看哪 | `[结尾状态]` 写死视线与构图重心 |
| 声音只有台词 | 画面质感少一半 | 每拍点名拟音（脚步/布料/器物） |
| 裸写"背对镜头"致朝向背反 | 视角与目标耦合，角色背对互动机器 | 正面朝向写明对准机器，后背迎向机位视锥，两套坐标解耦 |
| 角色眼神直视镜头（死鱼眼穿帮） | AI 默认正面注视肖像先验 | 声明视线绝对钉死在目标，与机位无眼神交互 |
| 转身如塑料陀螺整体平移 | 缺少下半身与重心传导 | 写以足底为轴心顺/逆时针旋转 N 度，躯干与头部逐级随动 |
| 机器人如铁坨呆立不动 | 缺少机械特有的微动态 | 写光学光圈对焦缩放、状态灯 1.5Hz 呼吸闪、伺服微颤 |
| 一开口说话角色就站住立正冻结（Talking Freeze） | 交叉注意力倾斜至口型，导致下半身动量归零 | 台词后强捆绑下半身动量延续（步频交替未停、重心前移）或作业不停，加否定禁令 |
| 说话时同框其他角色像假人蜡像 | 未发声角色缺乏独立动力学 | 声明听者独立动作轨迹：重心换脚、背带受力调整、伺服自检微颤、衣摆随风随动 |

## 七、改写示例（同一事件的两种写法）

**死画面版**（信息为零，动作无因果）：

```
[节拍 1] 镜头：中景，固定。画面：她走到门口，看着外面。神态：平静。环境：风。
音效：风声。仅此一类，无其他声音。
```

**生动版**（动机明确、环境被推动、材质可见）：

```
[节拍 1] 镜头：机位齐她肩高，门框把画面切成 2:1，她站在窄的一侧，固定。
画面：她右手先抬到门框上（指腹压住木面，压出一道浅白痕），重心前移到左脚，
      肩线跟着转 15°，衣摆晚半拍才甩过来；视线越过门缝投到外面。
神态：眼睑眯到只留一条缝，眉头向中间收 2mm，嘴唇闭合，鼻翼随吸气张开一次。
环境：门缝漏进的光带在她手背上扫过 15°，浮尘在光带里翻涌；门外风把她的发梢
      从画面左侧吹向右侧，每秒 2 次，幅度 1-2cm。
音效：掌心压上木门框的一声闷响（约 0.2 秒）；衣料摩擦；门外风掠过门缝的短促气声。
      仅此三类，无其他声音。
```

差别不在文采，在于：**观众能看出她要干什么、门有多重、风从哪来**。
