# 节奏与1.3倍速参照

《欺诈之地》当前用户认为约1.3x才接近正常剧作；作为本项目试剪参照，不推广成所有剧目硬规则。先比较同一代表性段落原版与加快版，记录实际采纳的区间/倍率；没有实际听看不能宣称观感已解决。

优先裁掉句前非剧情笑声、冗余建立镜、长尾停顿和动作完成后无信息的空白，按反应/接触切，不先整片机械提速。合适时做J/L剪辑，但不能切断辅音、气口或关键接触。调整对白、动作、情绪落点各自的持续时间。
如需1.3x对照，使用现有 FFmpeg 同步 `setpts=(PTS-STARTPTS)/1.3` 与 `atempo=1.3`（保留音高），保留原版并另存候选。变速需视频重编码，不称视频无损，不拿改播放帧率替代音画同步。字幕、音效、章节、审查时间码按同一编辑映射更新；剪掉区间不能只做全局除法。

检查：实际时长、音画同步、对白可懂度、角色音色、动作接触可读性、完整解码、字幕与拟音对齐、版本哈希。加速不能修正动作因果、身份错误或非剧本笑声；不因速度变快免除审查。输出项目内编辑决策与候选文件，只使相应剪辑/混音/审查失效，不重生全部视频。
