# 声音处理
## 适用与不适用
只处理当前工序。按项目目标选择，不要求所有项目执行本工序。
## 输入与前置检查
读项目计划、上游产物、所选技能版本和验收标准。检查真实文件、工具依赖及必需输入；缺失则 blocked，不猜测成功。
## SOP 与工具
按需读取 [技术参考](references/legacy-techniques.md)，调用 `scripts/cinematic_audio_mixer.py`；先看 --help 与依赖。参考中的旧固定八镜、统一时长、强制运镜轮换、凝视、性能及改善比例均为历史配方或未复核描述，不是本项目通用要求。只采用与实际能力相符的部分。
## 输出与保存
按 plan 约定输出到项目目录，返回路径、实际参数、输入与产物哈希及工具结果；不要将运行状态写进技能目录。
## 完成证据
物理完整性检查和内容审查分别记录。缺证据标记 needs_review；关键检查失败不得交给下游作为合格产物。
## 失败与恢复
暂态最多重试两次、质量返工最多两轮。先查已有任务与产物，不重复提交未知任务；依赖变化只返工相关下游。角色审查不能由 agent 代签人工。
## 可替换与约束
风格、镜头、配方可换；模型物理限制按实际服务检查。更换后记录来源和版本，保留旧版，按固定案例比较后激活。


## 实际检查能力
- scripts/audio_gate.py 用于选定的降噪；scripts/cinematic_audio_mixer.py 用于侧链混音，压缩量取决于信号电平，不保证固定分贝。
- H3 路径的 check_audio_seg.py 只做能量/时序启发式检查，其 PASS 不证明台词正确。
- 需要逐字检查时使用兄弟 comfy-h3-video-producer/scripts/check_dialogue_asr.py；配置 H3_ASR_PY 和 H3_WHISPER_MODEL 指向已有环境及本地权重，缺少时标记待审，不自动下载模型。
- ASR 的语言提示不是独立语种置信检测。口型、口音、声音身份仍需实际收听/看片或具备该能力的评审者。
