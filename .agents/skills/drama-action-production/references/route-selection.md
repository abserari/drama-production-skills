# 动作路线小样与激活

选一个带确切接触的交锋（如挥刃→挡住→双方分离），可加一个走位/闪避例；保持相同身份、道具、场景、动作目标、预算与目标规格。记录所需输入/安装认证、实际用时、峰值显存（可获取时）、成功/总尝试、选中/失败版本及问题。没有数据填写未验证，不给假评分。

- H3 专用动作配方：减少每镜主体/动作数量，强化路径与接触点，台词另镜制作。使用原生图或已握手导演台，不能把同事路径限制套到全部模型。
- 其他视频模型或运动参考路径：先检查本机已有服务、模型和可执行工作流；镜头关键帧/身份接口不同则由 agent 做明确输入转换。记录来源版本与授权，复用现有工具，不新增宿主框架。
- 剪辑路径：可拆为进攻、接触、反应、落位，动作衔接要在真实画面中可读；不可用插入光效掩盖未生成的关键格挡。

分别比较接触成立、身份/武器连续性、动作速度与成片节奏、有效片段率、成本；一条路线小样通过后才批量切换。同样目标可保留两条并行候选，但GPU任务串行；回滚不改变无关工序。节奏可对照本项目1.3x观看参照，不能把提高播放速度当作修复穿模/假接触。

## 后续扩展钩子：参考驱动的动作拆解（本轮不展开）
用户确认当前优先改善动作拆解，后续可从网络打斗片段借鉴有冲击力的视角与运镜。下次触发动作优化时，先收集合法可用的参考链接、来源和时间码，拆出攻击/格挡/闪避/受力/落位，再标注景别、机位高度、轴线、相机轨迹与切点，转换为本项目动作分镜和短试片。参考提供动作语法，不照搬身份、服装或场景，不把“炫酷运镜”当作缺少接触因果的补救。本轮只保留入口，不检索、不下载、不启动渲染或模型选型。
