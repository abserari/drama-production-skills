# 视觉资产与首帧
## 适用与不适用
只处理当前工序。按项目目标选择，不要求所有项目执行本工序。
## 输入与前置检查
读项目计划、上游产物、所选技能版本和验收标准。检查真实文件、工具依赖及必需输入；缺失则 blocked，不猜测成功。
## SOP 与工具
当用户要求参照原作/网络原图、保持角色身份或否决已有形象时，先执行 [参考驱动三要素资产](references/reference-grounded-assets.md)：核实具体对象，记录来源与用途，再生成人物、场景、道具候选。不要凭印象补造原设。
按需读取 [技术参考](references/legacy-techniques.md)，调用 `scripts/keyframe_gate.py`；先看 --help 与依赖。参考中的旧固定八镜、统一时长、强制运镜轮换、凝视、性能及改善比例均为历史配方或未复核描述，不是本项目通用要求。只采用与实际能力相符的部分。
## 输出与保存
按 plan 约定输出到项目目录，返回路径、实际参数、输入与产物哈希及工具结果；不要将运行状态写进技能目录。
## 完成证据
物理完整性检查和内容审查分别记录。缺证据标记 needs_review；关键检查失败不得交给下游作为合格产物。
## 失败与恢复
暂态最多重试两次、质量返工最多两轮。先查已有任务与产物，不重复提交未知任务；依赖变化只返工相关下游。角色审查不能由 agent 代签人工。
## 可替换与约束
风格、镜头、配方可换；模型物理限制按实际服务检查。更换后记录来源和版本，保留旧版，按固定案例比较后激活。
