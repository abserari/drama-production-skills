## 本机实际媒体实验
RTX 4080、16GB 显存，ComfyUI 0.35.0，PyTorch 2.6.0+cu124。采用原生 FL2VA/I2V 图，不依赖缺失的 CSGlide 节点；服务持续在 127.0.0.1:8188，生成队列已完成。

三个镜头均为 832×480、24fps、124 帧，带音轨；完整解码和音频能量检查通过。第一段采样后保存失败，修正新版 SaveVideo 的扁平参数后复用缓存导出，原失败回执保留。第二段实测约 302.0 秒；第三段最终版约 286.7 秒。采样期间观测最大显存 15909 MiB；观测从第一段结束后开始，不当作全程严格峰值。

第三段因摘掉护目镜做了一轮局部返工。新版本保留护目镜并完成金属杯抓放，旧视频/抽帧/审查均保留。杯子精确归位仍有偏差，不能当作内容全合格。

已生成 15.533 秒三镜诊断拼接片；一段 RealESRGAN x2plus GPU FP16 超分至 1920×1080，124 帧推理约 23 秒。重跑最终封装路径后，输出音频包 SHA256 与原片完全相同。证据和可复查脚本：工作区 production-validation/native-h3/verification-report.json、upscale-verification.json、verify_outputs.py。
