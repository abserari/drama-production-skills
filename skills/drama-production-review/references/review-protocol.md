# 抽样、证据与返工

抽样默认为百分之二十。先将首次风格/样本以及新角色、场景、技能版本对应对象加入必检集合，再对剩余对象抽样。用 SHA256(project_id + policy_version + 固定种子 "review-v1" + artifact_id) 排序，选前 ceil(剩余数量×0.2) 个；剩余非空至少一项。保存候选全集、入选对象及种子，保证可复查。抽样只降低人工/内容审查数量，必需文件完整性和交付数量检查不能抽样。

人工定调可引用先前已明确的用户选择，无需反复询问。未确认的样本进入 needs_review；不能把沉默当批准。低成本无关工序可以继续，依赖该决定的生产阻塞。

证据写明文本行/镜头 id、时间码、抽帧路径、ASR 差异或 ffprobe 结果，绑定当前 SHA256。无媒体查看/收听能力则相关项未验证，不用文件名代替质量结论。

关键失败示例：必要台词缺失、身份错乱、关键道具不可辨、缺镜、音画明显失步；以项目验收要求为准。偏好争议如静态镜头或色调差异应标为风格判断，不能伪装成物理限制。

返工记录保存 attempt、fixed、residual、new_issues、action、result_hash。最多两轮质量返工；连续无改善或出现更严重问题则停止自动返工。性能指标和评分应写实测值；未测就填 null 或明确 unknown，不填写经验保证值。
