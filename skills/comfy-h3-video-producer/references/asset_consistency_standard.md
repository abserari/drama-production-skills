# 资产一致性生产规范 (Asset Consistency Standard)

本规范定义短剧自动化管线中的三类核心资产标准：**角色资产卡**、**关键道具资产卡**、**场景正反打双向资产卡**。
旨在彻底解决分镜切换时“场景细节漂移”、“人物朝向翻转/背对”以及“道具形变穿模”三大行业痛点。

---

## 1. 三类核心资产卡标准矩阵

| 资产类型 | 构图规格 | 核心结构设计 | 作用与管线职责 |
| :--- | :--- | :--- | :--- |
| **① 角色资产卡 (Character Turnaround)** | 16:9 纯白底横幅 | **2+3 头身解耦布局**：<br>左侧 1/3 纵排双头部特写（正面+侧颜）；<br>右侧 2/3 无头全身服饰三视图（正/侧/背）。 | 锁定角色的脸型五官、发型发色、服装结构层次与材质质感。全身视图截除头部避免脸崩。 |
| **② 关键道具资产卡 (Key Prop Sheet)** | 16:9 或 1:1 纯白底 | **多角度与核心结构拆解**：<br>正面主视、侧视截面、局部细节透视、握持手部尺度对比。 | 锁定武器、任务道具、信物等几何外观、尺度锚点（标明长宽高cm）、磨损做旧细节与发光特征。 |
| **③ 场景正反打双向卡 (180° Reverse-Angle Scene)** | 16:9 横向双联排版 | **正反打两个方向并置**：<br>左侧 1/2 为 `0° 正打主视角 (Forward View)`；<br>右侧 1/2 为 `180° 反打逆视角 (Reverse View)`。 | **全剧空间一致性灵魂**。正反打视图共享统一世界坐标系、统一主光源角度、统一 3 个地标锚点，杜绝正反打背景脱节。 |

## 2. 场景正反打双向资产卡 (180° Reverse-Angle Scene Sheet) 规范

### 2.1 为什么必须用一张图做正反打两个方向？
在影视对话与对峙戏中，摄像机频繁在两人之间做**正打（Over-The-Shoulder / Reverse Shot）**切换。
若正反打场景作为两张图分别独立生成，极易发生“正看是木质酒架，反打看门口突然变成金属科幻走廊”的严重空间割裂。
**一张图双联同框渲染，能强迫模型在一个潜空间中共享同一套建筑材质、同一套环境光照色温、以及相互镜像投射的空间逻辑。**

### 2.2 正反打卡构图规范
- **左侧 1/2 (View A - 0° 正打主视角)**：从入口/前景望向主焦点（如：看向珍珠酒馆生铁吧台与后方发光酒架）。
- **右侧 1/2 (View B - 180° 反打逆视角)**：站在主焦点回望入口/背景（如：从吧台操作区回望进门气密门、外景风沙与客座区）。
- **中缝分割**：2px 纯垂直平直中线，两视图地平线水平对齐，色调与光影严格呼应。
- **三地标锚定法则 (3-Landmark Rule)**：
  - 地标 1（中心物体）：如生铁吧台（在 A 视图中见正面，在 B 视图中见背面操作台）；
  - 地标 2（高位物体）：如天花板悬挂的锈铁链吊灯（A 与 B 均可见，且悬挂位置坐标一致）；
  - 地标 3（地面物体）：如地面中央铁格栅排水槽（贯穿 A 与 B，形成空间透视灭点导向）。

## 3. 关键道具资产卡 (Key Prop Multi-Angle Sheet) 规范

- **单图承载**：纯白底摄影棚布光，无背景杂物；
- **尺度锚点**：必须写明物理尺寸（例如：`匕首全长38厘米，刃长24厘米，柄长14厘米`）；
- **材质标注**：明确金属光泽、做旧磨损、划痕刻字与非金属部件（例如：`哑光黑钨钢刀身，微弱拉丝研磨痕，刀柄为防滑硬质橡胶带两颗内六角黄铜铆钉`）；
- **禁止**：禁止人物手部遮挡关键结构，禁止处于运动模糊中。

## 4. 资产卡在视频生产提示词中的引用规范

在各段 `prompt` 的 `subject_definitions:` 中：
```markdown
subject_definitions:
- <Subject 1> 为 @角色卡 中的萨儿 (Sal)，尺度锚点=身高1.75米。权限=锁定角色五官发型与风衣结构，不复制参考图机位，不复制占画比例。
- <Subject 2> 为 @场景正反打卡 中的珍珠酒馆空间，尺度锚点=吧台长4米高1.1米。权限=锁定酒馆两向正反打空间结构与主光源色调，不复制原图机位，不复制占画比例。
- <Subject 3> 为 @道具卡 中的复合合金短刺，尺度锚点=长38厘米。权限=锁定短刺黑色涂装与双刃开刃结构。
```
