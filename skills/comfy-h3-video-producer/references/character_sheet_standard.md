# 工业级角色资产设定卡 (Character Reference Sheet) 提示词规范

本规范定义跨镜头、跨片段保持角色一致性的基准“2+3 角色五视图资产卡”标准。
采用**头身解耦设计**，彻底解决大模型在全身像中无法精细刻画面部特征的痛点。

---

## 1. 结构与视觉布局 (2+3 黄金构图)

| 区域 | 占比 | 包含视图 | 构图与展示重点 |
| :--- | :--- | :--- | :--- |
| **左侧区域** | 水平约 1/3 (纵向排列) | ① 上方：角色正面头部特写<br>② 下方：同一角色侧脸头部特写 | 集中潜空间分配面部轮廓、发型发丝、五官比例、耳部、下颌线、机械义体/义眼细节。中间保持干净留白。 |
| **右侧区域** | 水平约 2/3 (横向并列) | ③ 正面服饰视图<br>④ 左侧面服饰视图<br>⑤ 背面服饰视图 | **颈部以下截除头部**，完整展示躯干至鞋底，专注服装款式、剪裁层叠、颜色搭配、材质纹理与鞋履细节。 |
| **视觉分隔** | 全画幅统一 | 2px 宽、`#E2E2E2` 浅灰色细分隔线 | 分隔线平直统一，纯净纯白摄影棚无缝背景 (`#FFFFFF`)，无环境噪点。 |

## 2. 标准通用模板 (Template)

```markdown
提取并保持人物的面部特征、脸型、五官比例、发型、肤色、年龄气质与身份一致性；提取并保持整套服装的款式结构、层次搭配、颜色组合、面料材质、纹理细节、裤装/鞋履关系与整体穿搭风格。

横向构图，纯净纯白色无缝背景，中性摄影棚灯光，柔和前侧平光，布光均匀，轮廓清晰，肤色自然，服装结构与材质纹理准确。
严格布局规范：画面水平左侧约三分之一区域纵向排列两张头部视图，上方为角色正面头部特写，下方为同一角色侧脸头部特写；左侧两张视图之间保持干净留白。画面右侧剩余约三分之二水平区域横向并列摆放三张视图，顺序为：正面服饰视图、左侧面服饰视图、背面服饰视图。右侧三张视图直接截除头部，画面从颈部以下开始展示身体服饰，不呈现头部。五个视图之间使用2px宽、#E2E2E2淡灰色的竖向或细分隔线，线条平直统一。

平视镜头，右侧三张服饰视图完整展示人物躯干至鞋底，无画面裁剪。人物自然直立站姿，双臂自然下垂，双手放松空手，无任何握持物品。左侧上方正面头部特写五官清晰；左侧下方侧脸头部特写展示同一人物侧脸轮廓、发型、耳部、下颌线与面部结构。

五张视图中，人物面部特征、发型、体型、肤色与身份比例保持统一；服装款式、结构层次、颜色搭配、材质纹理、褶皱细节与伤痕污渍位置以[参考角色特征/参考图]为准，并在五个视图中保持一致。禁止任何道具、武器、食物、饮品、手持物品；禁止大幅度动作、夸张表情、强烈情绪、面部遮挡。无环境场景，仅纯白背景，不存在其他人物。无文字、水印、标签、标注、尺寸标识、Logo、UI界面元素。
```

## 3. 在管线中的落地规范

1. **画面宽高比**：推荐 **16:9**（如 `1536×864` 或 `1344×768`）或 **21:9** 超宽画幅，保证右侧三视图水平延展不拥挤。
2. **后处理裁剪与拆解**：
   - 提取左侧头部正面作为 `<Subject>` 核心头像参考；
   - 提取右侧正面作为全身着装与体态参考；
   - 保存至工程目录 `assets/character_sheets/`。
