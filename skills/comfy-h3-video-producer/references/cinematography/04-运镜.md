# 02 · 运镜

运动只用三个参数描述：**做什么（种类）· 多快（速度）· 到哪停（终点）**。
缺任何一项，模型都会自己发挥——而它发挥的方式通常是"缓慢漂浮"，也就是最廉价的 AI 感。

---

## 一、十二种运动 + 句式

### 1. 固定 Static / Locked-off
- **句式**：`相机完全固定在三脚架上，画面无任何位移`
- **效果**：稳、克制、让内容自己说话。也是**唯一不会翻车的运动**。
- **注意**：不写"固定"，模型默认会加一点缓慢漂移。要真的不动，必须明写。

### 2. 推进 Push In / Dolly In
- **句式**：`镜头在 5 秒内匀速推进，从[起始景别]推到[结束景别]，终点停在[某细节]`
- **效果**：逼近、揭示、压迫感上升。观众的注意力被物理收窄。
- **要点**：**必须写终点**。"推进"不写终点＝模型推到一个随机位置。

### 3. 拉出 Pull Out / Dolly Out
- **句式**：`镜头从[细节]缓慢拉出，露出[更大的环境]，终点是[全景]`
- **效果**：揭示真相、孤独感、把人物还给环境。
- **要点**：拉出常和"人物原来身处险境/荒芜"绑定，是结尾镜头的高频选择。

### 4. 摇 Pan（左右）/ 俯仰 Tilt（上下）
- **句式**：`镜头水平向右摇，扫过[场景]，停在[目标]`／`镜头向上仰，从[低处]抬到[主体顶部]`
- **效果**：不移动机位，只转视线。适合扫视环境、揭示相邻关系。
- **要点**：给"停在哪"，否则会摇过头。

### 5. 平移 Tracking / 侧移 Truck
- **句式**：`镜头与人物平行横移，速度与人同步，背景持续向反方向流过`
- **效果**：陪伴感、行进感；背景流动本身就是节奏。
- **要点**：横移会暴露空间，场景越完整越好看。

### 6. 跟随 Follow
- **句式**：`镜头在人物身后跟随前进，保持[中景]距离，随人物转向同步转向`
- **效果**：跟随、窥视、代入。开场常用。

### 7. 升降 Crane / 升降台 Pedestal
- **句式**：`镜头从地面升起到[高度]，视角由平视转为俯视，终点是[布局全貌]`
- **效果**：从个体到环境，一个镜头完成"放大尺度"。
- **注意**：升降常被误写成"无人机"，两者起始高度不同，写清起点。

### 8. 环绕 Arc / Orbit
- **句式**：`镜头绕主体逆时针环绕约 90 度，主体始终居中，背景持续旋转`
- **效果**：产品展示、英雄时刻、关系确认。
- **要点**：环绕是最容易"糊"的运动之一。**别叠加推拉**。

### 9. 手持 Handheld
- **句式**：`手持，轻微不规则抖动，人物走动时机位跟着起伏，画面不做稳定`
- **效果**：纪实、混乱、贴身、紧张。
- **要点**：抖动的**幅度**要写（"轻微"／"明显"），否则模型要么稳如三脚架，要么晃到看不清。

### 10. 斯坦尼康 Steadicam
- **句式**：`斯坦尼康稳定器，机位平滑前移，穿过[空间]，全程无抖动`
- **效果**：流畅穿行、长镜头、"漂浮感"。
- **对应索引**：GrokFilm 025

### 11. 变焦 Zoom
- **句式**：`镜头变焦推近，透视关系不变，画面整体放大`
- **效果**：快速强调。**变焦是"放大"，推轨是"走过去"**——两者透视变化完全不同，别混用。

### 12. 推轨变焦 Dolly Zoom
- **句式**：`机位向前推进的同时镜头反向变焦，主体大小不变，背景被拉伸`
- **效果**：眩晕、认知崩塌、世界失衡。一次片子最多用一次。
- **对应索引**：GrokFilm 231

### 加餐：甩镜 Whip Pan
- **句式**：`镜头快速甩向[方向]，画面出现运动模糊，末端停稳`
- **效果**：粗暴换场，也可以当遮挡切用（甩镜中间的模糊正是切点）。
- **对应索引**：GrokFilm 101

## 二、速度词（必须给）

| 词 | 每秒位移感 | 用在哪 |
|---|---|---|
| 极缓慢 | 几乎察觉不到 | 情绪、悬念、让观众自己发现 |
| 缓慢 / 匀速 | 明显但温和 | 常规叙事 |
| 中等 | 有推进感 | 信息揭示 |
| 快速 | 有冲击 | 动作、转折 |
| 急速 / 甩 | 带运动模糊 | 换场、惊吓 |

写法：**给时间**比给形容词可靠——`5 秒内推到水珠特写` 比 `缓慢推进` 稳得多。

## 三、运动与角度怎么配

| 机位 | 顺的运动 | 别配 |
|---|---|---|
| 低角度仰拍 | 向上摇、推近、升起 | 向下拉（会泄气） |
| 高角度俯拍 | 向下压、缓慢降 | 向上摇 |
| 俯拍正扣 | 缓慢旋转、固定 | 大幅横移 |
| 地面机位 | 沿地面贴地推进 | 升起 |
| 航拍 | 前进、环绕、拉升 | 定点长焦推（像监控） |
| 过肩 | 缓慢越过肩膀推进 | 大范围环绕 |
| 第一人称 | 手持、随动作摆动 | 平滑轨道（会失去主观感） |

**竖屏（9:16）专用**：沿镜头轴的推拉、上下摇、升降最合适；横移和左右摇会把主体很快挤出画面（见 `05-构图与画幅.md`）。

## 四、四条硬规则

1. **一条片段只给一个运动。** 推＋环绕＋变焦＝糊。复杂运动拆成两段，各自写起止，在剪辑点接。
2. **每个运动都要有终点。** "推进"必须写清推到哪；"摇"必须写清停在哪。
3. **要静止就明写。** `相机固定在三脚架上，画面无位移`。
4. **锚定机位**：`机位架在桌面、离杯底几厘米` 比 `低角度` 更能扛住模型重写。

## 五、一镜到底与遮挡转场

AI 片段之间最好用的缝合方式，不是硬切，是**让一个东西从镜头前扫过**。

| 手法 | 做法 | 提示词要写什么 |
|---|---|---|
| 遮挡切 Wipe | A 镜末段被物体/人体/水汽/黑场填满，B 镜开头从同样填满的状态开始 | 写**物理过程**："一块布完全盖住镜头"，不要写"无缝转场" |
| 动作切 Cut on action | 在动作中段切，两镜动作接得上 | 两镜写同一个动作的不同阶段 |
| 匹配切 Match cut | 形状/构图/运动方向一致 | 两镜的主体位置与运动方向对齐 |
| 甩镜 Whip | 快速甩动，模糊中切 | 写出甩的方向与模糊 |
| 首尾帧桥接 | 给模型首帧与尾帧，让它补中间 | 尾帧用同一套构图描述，只改景别 |

**注意**：两次生成永远不可能在同一状态精确相遇。必须靠遮挡（水、烟、布、黑场）时，把"完全覆盖"的那一下放到剪辑里做一层过渡，比指望模型对上更省事。

## 六、模型侧的运镜故障

| 故障 | 处理 |
|---|---|
| 不写运动就缓慢漂移 | 明写"固定" |
| 推进没终点，推到奇怪位置 | 写"5 秒内推到 X，停住" |
| 环绕叠加推拉后糊 | 拆成两条片段 |
| 斜角/鱼眼在片中自己扶正 | 视频提示词里重复"地平线保持倾斜" |
| 手持写成"晃动"后晃到不可用 | 给幅度：轻微／明显 |
| 一镜到底越到后面越崩 | 单段控制在 6–10 秒；要长就靠遮挡切接起来 |
