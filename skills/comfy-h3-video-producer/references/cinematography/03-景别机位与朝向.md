# 01 · 景别、机位、朝向、镜头

四组词回答前四个决策。每条给：**凭什么有效 / 什么时候失效 / 中英词 / 句式**。
写提示词时按这个顺序取词：距离 → 高低 → 朝向 → 镜头，不要跳。

---

## 一、距离（景别）

判定口径：**主体（人）占画面高度多少**。人物在画面里越满，信息越少、情绪越重。

### 大远景 ELS / Extreme Long Shot
- **占幅**：人 ≤ 1/8 画面高，环境主导。
- **凭什么有效**：比例本身就是内容——人在天地间只是一个小点，孤独、渺小、宿命感不用演，靠比出来。
- **什么时候失效**：要表情、要台词、要读文字时全废。人物的脸在这个尺度上只是一块色斑。
- **句式**：`大远景，人物在画面下三分之一处极小，[环境]占据画面主体，天地交界线压在画面上三分之一`
- **对应索引**：GrokFilm 008（Extreme Long Shot）

### 远景 / 全景 Wide（WS）
- **占幅**：人 1/4–1/2，能看到全身与周边。
- **凭什么有效**：交代"他在什么环境里、和什么发生关系"，是动作与空间的说明书。
- **什么时候失效**：承担情绪。宽画面里的人脸会糊，模型尤其如此。
- **句式**：`远景，人物全身入画，[环境]完整可辨，人物与[关键道具]的距离关系清楚`
- **对应索引**：GrokFilm 244（Wide Shot）/ 006（Establishing）/ 012（Helicopter）

### 中景 Medium（MS）
- **占幅**：腰以上 / 物体加周边。
- **凭什么有效**：**最稳的工作镜头**。既有表情又有动作，还能看见手在干什么。对话戏与产品演示的主力。
- **什么时候失效**：想让人震一下、或者想藏信息时——中景什么都给了一点，什么都不狠。
- **句式**：`中景，人物腰部以上入画，身后[环境]轻度虚化，双手动作在画幅内清楚`
- **对应索引**：GrokFilm 018（Medium Shot）/ 105（Medium Close-Up）/ 017（Master）

### 近景 / 特写 Close-Up（CU）
- **占幅**：头肩 / 物件填满画面。
- **凭什么有效**：压缩环境、放大情绪。观众被迫只看一件事，注意力被锁定。
- **什么时候失效**：承担"交代"。特写里没有空间关系，观众会迷失方位。
- **句式**：`近景，人物面部填满画面，背景完全虚化，焦点在眼睛`
- **对应索引**：GrokFilm 003（Close-Up Shot）

### 大特写 / 微距 ECU / Macro
- **占幅**：一只眼、一只手、一滴水。
- **凭什么有效**：放大到肉眼平时看不见的层面，制造压迫、生理感、悬念。恐怖片里比全景有效得多。
- **什么时候失效**：连续使用。三个大特写接在一起，观众失去方位感，只剩烦躁。
- **句式**：`大特写，只取[眼睛/手指/水珠]，100mm 微距，f/2.8，边缘柔化`
- **对应索引**：GrokFilm 007（Extreme Close-Up）

## 二、高低与水平（机位高度）

判定口径：**相机相对主体眼睛的高度**，以及**地平线是否水平**。

### 平视 Eye-Level
- **凭什么有效**：没有权力倾向，观众与角色平等。日常视角的默认值，也最不容易出错。
- **什么时候失效**：**从来不会"失效"，只会"无聊"**——因为它是默认值，不选择它反而更危险。
- **句式**：`平视，机位与人物眼睛同高，地平线水平`
- **对应索引**：GrokFilm 009（Eye-Level Shot）

### 低角度 Low-Angle
- **凭什么有效**：仰视让主体占据画面上方，天然产生压迫与崇高。人物显得强、物体显得贵。
- **什么时候失效**：给弱者用会读成讽刺；连续仰拍会显得宣传片。
- **句式**：`低角度仰拍，机位低于主体腰部向上看，[主体]显得高大，背景是天空`
- **对应索引**：GrokFilm 016（Low Angle Shot）

### 高角度 High-Angle
- **凭什么有效**：俯视压缩主体，人变小、变弱、被环境吞掉；也用来一次把布局摊给观众。
- **什么时候失效**：想要压迫感时用反了——俯拍会让反派显得可怜。
- **句式**：`高角度俯拍，机位高于主体向下看，[地面/桌面]在人物周围展开`
- **对应索引**：GrokFilm 013（High Angle Shot）

### 俯拍正扣 Overhead / Top Shot
- **凭什么有效**：相机垂直向下，立体空间被压成平面图形——布局、阵型、图案第一次变得可读。也是"上帝在看"的疏离感。
- **什么时候失效**：人脸在这个角度几乎没有表情，别让它扛情绪。
- **句式**：`正俯拍，相机垂直向下，主体在画面中央，[桌面/地面]的线条构成图案`
- **对应索引**：GrokFilm 002（Bird's Eye View）/ 020（Overhead）

### 鸟瞰 / 航拍 Aerial
- **凭什么有效**：尺度、地理、自由运动。开场定调最有效的一招。
- **什么时候失效**：人物戏。航拍里人只是坐标。
- **句式**：`航拍，高角度越过[地形]，主体极小，[地标]入画`
- **对应索引**：GrokFilm 001（Aerial）/ 012（Helicopter）

### 地面机位 Ground-Level
- **凭什么有效**：相机贴地被前景物体挡住一半，观众被扔进现场，前景道具被放大成巨物。
- **什么时候失效**：地面材质差的时候全片露怯。
- **句式**：`机位贴在[地面/桌面]，距离几厘米，前景[物体]在画面下缘放大，主体在后景升高`

### 虫视 / 极仰 Worm's-Eye
- **凭什么有效**：极端的垂直仰视，主体像纪念碑。
- **什么时候失效**：模型容易把它画成普通仰拍；要靠"最近的部位在前景被放大"来钉住。
- **句式**：`虫视，从[主体]正下方极陡向上看，[最近部位]在前景夸张放大，顶部是天空`
- **对应索引**：GrokFilm 116（Worm's Eye View）

### 斜角 Dutch Angle / Canted
- **凭什么有效**：把地平线拧歪，一个镜头就让观众"觉得不对"。不安、失衡、醉、失控。
- **什么时候失效**：全片都用＝风格噪音；模型还会在片段中途把地平线"扶正"。
- **句式**：`斜角，画面整体倾斜约 25 度，[场景里的直线]在画面中呈对角线`
- **对应索引**：GrokFilm 004（Dutch Angle）

## 三、朝向（看哪一面 / 谁的眼睛）

### 正面 Front
- **凭什么有效**：最直接、最有对抗性，适合对峙与宣言。也是证件照感。
- **什么时候失效**：想藏信息时。

### 侧面 Profile
- **凭什么有效**：轮廓、剪影、沉思。信息少但形状强。
- **什么时候失效**：需要看眼神和反应时。侧面会切断情绪。
- **句式**：`侧面，人物正对画外，轮廓干净，光从一侧擦过`
- **对应索引**：GrokFilm 240（Profile Shot）

### 四分之三 Three-Quarter
- **凭什么有效**：**最好看的默认值**。既见脸又见体积，还有一点纵深。
- **什么时候失效**：几乎不失效；只是不够狠。
- **句式**：`四分之三侧，人物相对镜头转约 45 度，正面与一侧同时可见`

### 背面 Rear
- **凭什么有效**：观众看不见脸，只能跟着看——神秘、跟随、代入。
- **什么时候失效**：需要情绪落点时。
- **句式**：`背面，人物背对镜头望向[画外目标]，脸部不可见`

### 过肩 OTS / Over-the-Shoulder
- **凭什么有效**：建立两人关系与空间位置，是对话戏的黏合剂。
- **什么时候失效**：过肩的肩膀太抢戏时会挡住主体。
- **句式**：`过肩，前景是[A]的肩与后脑（虚），焦点落在[B]的脸上`
- **对应索引**：GrokFilm 019（Over-the-Shoulder Shot）

### 第一人称 POV
- **凭什么有效**：观众成为角色，代入感最强。
- **什么时候失效**：手是模型的弱项，动作一大就穿帮。
- **句式**：`第一人称，画面下缘露出自己的手正握着[物]，视线看向前方[场景]`

### 自拍 Selfie
- **凭什么有效**：UGC 真实感、手机原生感；竖屏最自然。
- **什么时候失效**：用在需要"被观看"的正式场景会显得廉价。
- **句式**：`手机自拍视角，单臂伸向镜头，广角轻微畸变，背景是[场景]`

## 四、镜头与焦点

### 焦段：这是"空间感"的总开关

| 焦段（全画幅等效） | 效果 | 什么时候用 |
|---|---|---|
| 14–24mm 广角 | 透视夸张、边缘拉伸、空间被撑大 | 要动感、要"逼近"、要空间纵深；**别用来拍脸** |
| 35–50mm 标准 | 接近人眼，最中性 | 叙事主力，对话、跟拍 |
| 85–135mm 中长焦 | 压缩背景、脸型好看、背景糊成奶油 | 人物特写、情绪；但会压扁空间 |
| 150mm+ 长焦 | 极致压缩，前后景贴在一起 | 窥视感、拥挤的人海 |
| 100mm 微距 | 放大细节，景深极浅 | 材质、水珠、纤维 |
| 鱼眼 | 强畸变、圆形成像 | 滑板/音乐/荒诞，一个段落最多一次 |

### 焦点

- **浅景深**（f/1.4–2.8）：只留一处清楚，其余化开。用于隔离主体、制造亲密。
- **深焦**（f/8 以上）：前后都清楚。用于群像、空间关系、命运感。
- **前景遮挡**：让一个虚的前景物挡在镜头前，画面立刻有层次，也天然藏住"AI 感"。
- **裂焦**：前景与后景同时清楚、中间虚——少用，模型也难稳。

### 句式

```
低角度近景，35mm，f/2，机位贴桌面；前景是虚化的杯沿，焦点在人物眼睛
```

---

## 五、取词顺序（写提示词时照这个来）

```
距离 → 高低 → 朝向 → 镜头/焦点
```

例：`大远景 + 航拍 + 背向 + 24mm 深焦` → "航拍大远景，人物背向镜头站在山脊上，24mm 深焦，天地全清"。

**禁止混搭矛盾的组合**：`俯拍虫视`、`微距大远景`、`广角长焦压缩`——模型会任选其一，等于没写。
