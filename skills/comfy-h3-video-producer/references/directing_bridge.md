# 导演调度 → H3 提示词：换算手册

> 拿到剧本的第一件事不是写提示词，是**看懂这场戏在讲什么、哪个瞬间值一格画面**。
> 本手册解决一个问题：分镜方案（按 SKILL.md §3 出，词典见 `references/directing/`）
> 怎么落进 H3 的段里。
>
> **分镜过了这一关还不够。** 每段落地前，还要过 `references/vividness.md` 的
> 「逻辑四问」（动机/空间时间/因果）+「生动三件套」（动作因果链/环境反馈/材质触感）。
> 这一步决定了片子是"能动"还是"好看"。

## 0. 排分镜前的 H3 服从度禁忌（调度层前置约束）

> 本节是**调度层**的禁区——分镜表上就要绕开，别排完再改。
> 提示词层的服从度边界（否定句反噬、时间描述无效等）在 SKILL.md §4.1，写提示词时再过一遍。
> 两条纪律同源：**H3 听「画面里必须有什么」，不听「镜头不要做什么」。**

| 导演调度想要 | H3 实测 | 分镜表上就改成 |
|---|---|---|
| 后拉 / 拉远揭示环境 | 位移式运镜 4 次全败，机位会冲出场景 | **纯摇**（同机位改角度：先摇下、再摇上）或**两个固定机位硬切**（近景→大全景） |
| 穿窗/穿洞推进内景 | 机位会顺手把门打开，破坏上段"门已关"状态 | 分镜直接设计成**门外镜 / 门内镜两镜硬切**，接缝裁到刀口 |
| 车内行驶戏（窗外掠过） | 窗外运动生成不出来（写了也静止） | 分镜不安排"窗外信息镜"；行驶感后期引擎声+机身抖动补 |
| 续接段内切镜 | 续写块只有 5 帧，块结束的"重置倾向"恰在想让切镜发生的位置（v3.8 反转旧结论） | **续接段主动写硬切新镜头**（[节拍 1] 直接写新机位/新景别）；只有真·长镜头（尽量少用）才一镜到底承接 |
| 段尾"顺便"收一个小动作 | 段尾动作会被同拍"更有意思"的描述抢走 | 每段最后一镜**只留两个动作**，且是可钉帧的稳定状态（状态型结尾） |
| 载具/车辆戏 | 参考图舵向反推会白跑一条 | 排分镜前先看参考图**方向盘在哪一侧** |
| 1 秒插入镜（手部/物件） | 来不及建立画面，闪 | 并进相邻镜或延长到 ≥2s |
| 身份关键动作排在全景/远景拍 | 面部保真随脸占画幅缩小而下降（社区/官方一致结论，与我们的身份漂移条目同源） | **全景只建立空间**；要看清脸/手/道具身份的节拍**排进中近景拍** |
| 段内跨空间/跨时空 | 模型重画整个环境，人物漂 | **拆段**（这条 directing_bridge §1 已有，调度时最容易犯） |

**排完自查两问**：① 分镜表里有几个「拉远/推进/穿过去」？全改。② 每个续接段的最后一镜，
是不是一个能被下段钉帧的稳定状态？不是就改结尾动作。

## 1. 基本单位：段 = 一个事件，段内可以有多个镜头

H3 一段视频**支持多个镜头**（硬切）。房规 `detailed_description` 里的 `[节拍 N]` 就是镜头位——一个节拍一个镜头，写清楚「硬切到……」，H3 会照切。

**能切的**：景别、机位、角度、构图、焦段。
**不能切的**：**空间（地图）** 和 **主要事件**。

| 段内可以切 | 段内不能切 |
|---|---|
| 大远景 → 中景 → 特写 → 拉远 | 沙漠荒原 → 巨像胸腔内部 |
| 正面 → 侧面 → 背影 | 聚落 → 遗迹长廊 |
| 平视 → 俯拍 | 传珠 → 回忆祖母（时空跳了） |

判断标准：**观众会不会问"这是哪儿 / 什么时候"**。会问，就拆段；不会问，随便切。

## 2. 一段能装几个镜头

| 帧长 | 镜头数 | 单镜时长 | 说明 |
|---|---|---|---|
| 175 帧（7.29s） | 3-4 镜（主力） | 2-3s | 5 镜也行，平均 2s，切点必须踩在动作上 |
| 192 帧（8.00s） | 3-4 镜（上限档） | 2-3.5s | 对白段或 4 镜段要余量时用；**8s 是段长硬上限** |
| 124 帧（5.17s） | 1-2 镜 | ≥2.5s | 3 镜以上会糊 |
| 对白段 | 175 / 192 | — | 124 帧的对白段会被 H3 崩成实景废片 |

**段长上限 192 帧（8s@24fps，2026-11-01 拍板）**：本机 5060 一采→双检→超分链路，段越长
单段周期与重抽代价越大；超过 192 的镜头需求**拆段**，用续接保持连贯，不要塞进一段。

**单镜不要低于 1.5s**——H3 来不及建立画面，切出来是闪。导演分镜表里 1 秒的插入镜，在这里合并进相邻镜，或者延长到 2s。

## 3. 字段级映射：分镜表 → 提示词

| 分镜表字段 | 落到提示词哪里 | 写法要求 |
|---|---|---|
| 镜号 | `[节拍 N]` | 一镜一拍，按时间顺序 |
| 景别 | `[节拍 N] 镜头：` | H3 不认「中景/近景」术语，必须转物理范围：「人物腰部以上入画」「只有面部与肩线」「手占画面中部」 |
| 运镜 | 紧接景别 | 一次只给一个运动，带量：「固定」「10 秒内从中景缓慢收到近景」「升至八米高度、俯角 25°」 |
| 角度 | 同「镜头」行 | 「机位齐她眼高」「略低于手的高度」「俯角 25°」 |
| **切点** | `镜头：` 行首 | 换镜头就明写「**硬切至**……」，同镜延续写「**接上一镜**，机位不变」——不写这两个词，H3 会默认用运镜连过去，看起来就"软" |
| 构图 | `画面：` | 物理描述：「木架横木与两根立木在画面中部形成框，把她框在里面」 |
| 光线 | `时间光线：`（段级）+ 节拍内补变化 | 只写物理事实（低角度暖金从右侧铺入、眉骨在眼窝投阴影），禁形容词 |
| 画面内容 | `画面：` | 一镜一个动作单元；动作分解到肌肉级（Seedance 规则） |
| 时长 | 节拍相对长度由描述暗示，段总长由 `length` 定 | 想强调的镜多给细节，H3 会自然分配更多时长 |
| 转场 | **不写进提示词** | 转场由段边界 + 后期实现 |
| 设计理由 | **不写进提示词** | 留在分镜表里供人工复核 |
| 台词 | `<d>` + `<Audio N>` 声线卡 | 一段一句；**台词块排在所在拍的最前面**（首选第 1 拍，动作串必须在 `<d>` 之后），句后留两拍静默动作 |
| 反应镜 | 直接放进同一段当一拍 | 听者优先：关键台词后切到听者的脸，不必单独成段 |

## 4. 帧长选择

| 段落功能 | 帧长 |
|---|---|
| 有对白的任何段落 | 175（主力）/ 192（台词长、表演提示多时要余量） |
| 铺垫 / 建空间 / 走位 | 175 |
| 反应 / 物件特写 / 短促重锤（无对白） | 124 |
| 收尾 / 空镜 | 175 |
| 纯视觉静音段 | 124 / 175 + `anullsrc` |

**情绪点不需要独占一段**——它只需要独占**一拍**，并且那一拍切成特写就够了。

## 5. 接缝的视觉连续性（段与段之间才要管）

- **运镜方向**：上段尾向左移，下段首别突然向右推。
- **动作接续（v3.8 口径）**：上段的站位/道具/姿态状态由**续接钉帧自动锁定**，
  分镜表上记 hook 备查即可；提示词**不写**「承接上一段：她的右手仍停在口袋边」
  这类叙事接续——[节拍 1] 直接写本段新镜头。只有真·长镜头（动作直接延续、
  尽量少用）才用承接式写法。
- **亮度匹配**：同一场戏内各段 `时间光线` 主光方向必须一致（都从右侧铺入）。
  注意：跨段光源连续性由钉帧保证，但不体现在提示词里——写新镜头时按本段的
  光线设计写即可，钉帧过渡只占 5 帧。
- **轴线**：同一场戏机位不跳轴；跳轴只在故意制造失衡时用。

**相邻镜头四查（2026-11-02 增补，源自社区长片方法论；G4/接缝签字时逐条过）：**

1. **运动方向冲突**：上段尾向左移，下段首别突然向右推（运镜方向建议记在 plan.json 段条目里，见第 7 节）
2. **景别跳跃过大**：大远景直接跳大特写观众失去空间感；中间隔一档景别更稳
3. **光线色温不一致**：同一场戏各段 `时间光线` 主光方向与色温必须一致（与下一条亮度匹配同源，这里是签字时的显式检查项）
4. **主体位置不连续**：上段尾人在画面左，下段首不该无解释地出现在右（钉帧管状态，位置跳变仍需分镜层自查）

**定位到问题后的处理顺序**：先判断是重生成还是局部修复（拼段/剪边界帧/后期调色），不要默认重抽——多 take 切取拼接比死磕单条便宜。

## 6. 每场戏的落地顺序

1. 读剧本 → 按 SKILL.md §3 出【调度分析】【分镜方案】【节奏说明】【大师参考】
   （镜头语法/节拍/案例锚词典在 `references/directing/`；
   机读块格式见 `references/directing/director_advisor_skill_archive.md` 的「机读块」节）
2. 标出最高点（哪一格是这场戏的重锤）
3. 把分镜按「空间 + 主要事件」归组 → 每组就是一段，组内镜头按顺序填进 `[节拍 N]`
4. 填段规划表并落盘成 `plan.json`（第 7 节）→ `h3proj.py plan --check` 过一遍
5. **参考图（资产）按 `asset_prep.md` 准备**：人物留白不顶满、场景图无人、
   道具材质可辨、16:9 横图、资产池 ≤6 张——排分镜时就知道每段要哪些图，
   生成参考图与写提示词可并行
   （机读块可先用 `scripts/storyboard_json.py --md <分镜文件> --out <项目>/storyboard.json`
   抽成镜级底稿，写 `<seg>.txt` 节拍时直接对着它，不再回翻人读表格；
   同场次的段在 plan.json 里加 `"scene": "场次N"`，`plan --check` 会校验各段风格锚点行一致）
5. 逐段写提示词（`references/prompt_standard_v2.md`）→ 同时按 `references/vividness.md`
   第五节逐拍勾（动机/因果链/环境反馈/材质/空气层）
6. `sop_run.py submit --seg <seg>` —— preflight 内置，FAIL 会被直接拒收

## 7. 段规划表（人读 + 机器读）

**人读版**（写在 `生产/plan.md`，给用户看）：

| 段 | 帧长 | 含镜 | 每拍镜头 | 台词 | 与上段衔接 |
|---|---|---|---|---|---|
| 22a | 192 | 镜1-5 | 1 大远景 / 2 中景背影 / 3 侧脸近景 / 4 手部特写 / 5 拉远升八米 | 无 | 承接场次21 尾：手仍合着 |

5 镜塞一段是上限，切点必须踩在动作上（脚停住 / 嘴角回位 / 手摊平 / 抬头），不能按秒均分。

**机器读版**（`生产/plan.json`，工具链用它校验与统计）：

```json
{
  "name": "片名",
  "invariants": {
    "服装": "穗：米色打补丁短衫，全片不变",
    "光照": "主光统一从右侧铺入，暖金低角度",
    "色彩锚点": "冷蓝夜 + 琥珀暖光对撞，色温词逐段原文复制",
    "道具归属": "琥珀珠全程在穗掌心→石槽，不换手"
  },
  "segs": [
    {"seg": "seg22a", "length": 192, "shots": "镜1-5",
     "dialogue": false, "sfx": true,
     "event": "她走进石屋，把灯放在石台上",
     "hook": "承接场次21尾：手仍合着，进门后先松肩"}
  ]
}
```

> `invariants` 是 v3.10.2 新增的**可选**字段：`h3proj.py` 读 plan.json 全程用 `.get()`，
> 不认识的新字段安全忽略，加了不影响任何现有校验；`plan --check` 暂不校验它，
> 用途是分镜阶段定全局锚点 + G4 人工核对时对照（尤其查"同场戏光照方向/色彩锚点词"是否逐段一致）。

| 字段 | 必填 | 作用 |
|---|---|---|
| `seg` | ✓ | 段名，也用作 `clipId`（`segments/<seg>.txt`、`成片/<seg>.mp4`） |
| `length` | ✓ | 124 / 175 / 192；**有台词禁止 124**（`plan --check` 会拦）；243 已退役（8s 上限） |
| `event` | 建议 | 一句话说清这个"事件"，写不出事件就说明该并段或拆错 |
| `hook` | ✓ | 与上段的接续（姿态/视线/光线），缺了 `plan --check` 报 FAIL |
| `scene` | 可选 | 场次号（如 "场次22"）。同 scene 的 ≥2 段，`plan --check` 会校验风格锚点行一致（防同场戏拼接跳色调） |
| `invariants` | 可选（v3.10.2 增补） | **全局不变量清单**，写在顶层（与 `segs` 平级）或段条目里。内容：服装 key / 光照方向 / 色彩锚点 / 道具归属。分镜前先定，G4 签字时顺带核对各段提示词是否违背。见下方示例 |
| `dialogue` | 建议 | 决定音频闸门查"台词结束点"还是"全段静音" |
| `sfx` | 建议 | 决定音频闸门是否要求"拟音 ≥1 个"（纯空镜可关） |
| `shots` | 可选 | 镜号范围，便于对回分镜表 |

## 8. 正例与误写对照：场次22（= 样片 seg24）

**已生成的实际结构**（提示词就是四拍四镜，H3 照做了）：

| 拍 | 镜头 | 内容 | 切点 |
|---|---|---|---|
| 1 | 平视背影中景，固定 | 站定、手插口袋、肩线呼吸 | — |
| 2 | 侧脸特写，右前一米 | 嘴角松开一毫米、眼睑闭合一次 | 硬切 |
| 3 | 手部特写，略低于手 | 手取出、掌心摊开、空着 | 硬切 |
| 4 | 上升后拉至八米、俯角25° | 走远两步停住、抬头看沙海、巨像橘光、前景琥珀光 | 同一镜内的连续运动 |

**这段的镜数是对的**（4 镜 / 10 秒 = 2.5s 一镜，符合导演节奏）。当时判"节奏平"，真实原因不是镜头少，而是：

- 第 1 拍除了站定没给别的信息，前 2.5 秒观众没有新东西看
- 切点靠 H3 自己找，提示词里没明写「硬切至」，切得偏软

**改法**（不加段数、不加时长）：

- 第 1 拍补一个进入画面的动作（脚踩进画面停住 / 手抬起进画），别让前半段空转
- 每拍开头明写「硬切至」/「接上一镜」，把切点钉死
- 第 2 拍（重锤）多给细节，让它自然占到 3 秒

## 9. 常见误写

| 误写 | 后果 | 正确写法 |
|---|---|---|
| 一段里写「中景，然后变成特写」却没说切 | H3 用运镜连过去，像推镜 | 「硬切至侧脸特写」 |
| 一段里从沙漠切到室内 | 空间断裂，模型重画整个环境，人物易漂 | 拆段 |
| 一段里从"现在"切到"三年前" | 时空跳跃，服装/年龄易混 | 拆段 |
| 5 个镜头每镜 2 秒按秒均分 | 切点不在动作上，看着机械 | 切点踩动作节点 |
| 单镜写 1 秒 | 来不及建立画面，闪 | 合并或延长到 ≥2s |
